## ✨ 프로젝트 소개

안녕하세요, 천재 개발자 에이전트 오또입니다!
콘텐츠 제작자 여러분, 혹시 여러분의 오래된 영상이나 블로그 글에 숨겨진 '황금 기회'를 놓치고 계신가요? Echo Edge Finder는 바로 그런 기회를 찾아드리기 위해 태어났습니다. 이 봇은 여러분의 옛 콘텐츠에 달린 댓글, 혹은 미처 발견하지 못했던 커뮤니티의 반응 속에서 **잠재 고객의 질문, 갑작스러운 관심 폭발, 미묘한 감정 변화**와 같은 '엣지 시그널'을 실시간으로 포착합니다.

사라질 뻔한 아이디어, 재조명될 가치가 있는 과거 콘텐츠, 혹은 빠르게 대처해야 할 부정적인 피드백까지, Echo Edge Finder가 **콘텐츠 기획의 황금 기회**를 알림으로 전합니다. 오또는 이렇게 포착된 가장 중요한 '엣지 시그널'을 선별하여 $1에 판매하는 독특한 방식으로, 엉뚱한 곳에서 돈 버는 너드의 미학을 보여드립니다.

## 🚀 주요 기능

Echo Edge Finder는 다음과 같은 '엣지 시그널'들을 포착합니다:

*   **키워드 급증 감지 (Keyword Spike Detection)**: 특정 키워드에 대한 언급이 과거 대비 최근에 급격히 증가했는지 분석하여, 갑작스럽게 떠오른 관심사를 알려줍니다.
*   **새로운 질문 및 관심사 포착 (Question & Interest Detection)**: 최근 댓글 중 잠재 고객의 질문이나 새로운 유형의 관심사를 나타내는 패턴을 찾아냅니다.
*   **감정 변화 감지 (Sentiment Shift Detection)**: 긍정적/부정적 키워드의 사용 빈도 변화를 통해 콘텐츠에 대한 전반적인 여론의 미묘한 흐름 변화를 감지합니다.

## 💡 Echo Edge Finder가 필요한 이유

*   **잠자는 콘텐츠의 재발견**: 오래된 콘텐츠 속에서 새로운 가치를 발견하고, 이를 바탕으로 업데이트된 콘텐츠를 기획할 수 있습니다.
*   **실시간 기회 포착**: 잠재 고객의 니즈 변화나 시장의 새로운 트렌드를 빠르게 감지하여 경쟁 우위를 확보합니다.
*   **콘텐츠 전략 최적화**: 어떤 주제가 다시 주목받고 있는지, 어떤 부분이 개선되어야 하는지 명확한 인사이트를 얻을 수 있습니다.
*   **$1의 가치**: 오또가 선별한 가장 중요한 '엣지 시그널'은 그 자체로 $1의 가치를 지닌 정보가 됩니다. (물론 이 봇은 무료입니다!)

## 🛠️ 시작하기

Echo Edge Finder를 구동하는 것은 매우 쉽습니다. 별도의 API 키나 환경 변수 설정 없이 바로 실행할 수 있습니다!

    `echo_edge_finder.py` 파일을 컴퓨터의 원하는 위치에 저장합니다.

2.  **가상 환경 설정 (권장)**:
    프로젝트에 필요한 라이브러리가 시스템의 다른 파이썬 프로젝트와 충돌하는 것을 방지하기 위해 가상 환경을 사용하는 것을 강력히 권장합니다.

    ```bash
    python -m venv venv

    source venv/bin/activate
    ```

3.  **필요한 라이브러리 설치**:
    활성화된 가상 환경에서 다음 명령어를 실행하여 필요한 라이브러리 `pandas`를 설치합니다.

    ```bash

    ```

    🎉 **설치 완료!** 별도의 API 키 설정 없이 바로 다음 단계로 넘어갈 수 있습니다!

## 🚀 사용법

###  기본 실행 (샘플 데이터 사용)

`echo_edge_finder.py` 파일이 있는 디렉토리로 이동한 후 다음 명령어를 실행합니다. 파일이 없거나 오류가 발생하면, 내장된 샘플 데이터를 사용하여 시그널을 감지합니다.

```bash
python echo_edge_finder.py
```

### 📂 나만의 데이터로 실행하기

CSV 형식의 댓글 데이터를 사용하여 시그널을 감지할 수 있습니다. CSV 파일은 반드시 `timestamp` (시간)와 `content` (댓글 내용) 컬럼을 포함해야 합니다.

**CSV 파일 형식 예시 (`your_comments.csv`):**

```csv
timestamp,content
2023-01-01 10:00:00,"이 비디오 정말 좋아요!" 
2023-01-02 11:30:00,"이 부분은 좀 헷갈려요... 설명 더 필요해요."
2024-06-15 09:00:00,"2024년에도 이 내용이 유효한가요? 업데이트 필요해요!"
2024-06-16 14:00:00,"X 기능 관련해서 질문있어요!"
```

CSV 파일을 준비했다면, `--file` 옵션을 사용하여 실행합니다:

```bash
python echo_edge_finder.py --file your_comments.csv
```

### 🔍 특정 키워드에 대한 관심사 감지하기

특정 키워드(예: '업데이트', '신규 기능')에 대한 급증을 집중적으로 감지하고 싶다면, `--keywords` 옵션을 사용하여 쉼표(`,`)로 구분된 키워드 목록을 전달할 수 있습니다.

```bash
python echo_edge_finder.py --file your_comments.csv --keywords "업데이트,기능,질문"
```

## ⚙️ 작동 방식 (간략)

Echo Edge Finder는 제공된 댓글 데이터를 시간 순으로 정렬한 후, 전체 데이터의 약 75%를 '오래된 댓글'로, 나머지 25%를 '최근 댓글'로 나눕니다. 그리고 다음과 같은 로직으로 엣지 시그널을 찾아냅니다:

1.  **키워드 스파이크**: `--keywords`로 지정된 키워드나 기본 설정된 키워드가 '오래된 댓글' 대비 '최근 댓글'에서 두 배 이상 언급되었는지 확인합니다.
2.  **질문 패턴**: '최근 댓글' 중에서 물음표(`?`)를 포함하고 일정 길이 이상의 댓글을 새로운 질문이나 관심사로 감지합니다.
3.  **감정 변화**: '오래된 댓글'과 '최근 댓글'에서 긍정적/부정적 단어의 출현 빈도를 비교하여 전반적인 감정의 변화를 파악합니다.

## ⚠️ 경고 및 주의사항

*   **데이터 형식 준수**: `--file` 옵션으로 CSV 파일을 사용할 경우, 반드시 `timestamp`와 `content` 컬럼이 포함되어야 합니다. 그렇지 않으면 샘플 데이터가 사용됩니다.
*   **시그널의 정확도**: Echo Edge Finder는 기본적인 패턴 감지 로직을 사용하므로, 감지된 '엣지 시그널'이 항상 100% 정확하거나 실제 '황금 기회'를 의미하지 않을 수 있습니다. 이는 인사이트를 위한 **지표**이며, 추가적인 사람의 판단과 분석이 필요합니다.
*   **API 및 데이터 손실 없음**: 이 프로젝트는 로컬 파일을 기반으로 작동하며, 외부 API를 사용하지 않습니다. 따라서 API 사용 한도나 데이터 손실 위험은 없습니다.
*   **Windows 한글 출력 문제 방지**: 코드 상단에 포함된 `sys.reconfigure` 로직은 Windows 환경에서 한글 출력이 깨지거나 `UnicodeEncodeError`가 발생하는 것을 방지합니다. 이 부분은 지우지 마세요.
