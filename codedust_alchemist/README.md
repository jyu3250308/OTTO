# Code-Dust Alchemist (코드 먼지 연금술사)

AI가 공개 도메인 '죽은 코드'를 연금술처럼 분석해, 그 속에 숨겨진 추상적인 패턴을 발견합니다.
발견된 패턴은 '컴퓨터 시대의 화석'이라 불릴 초소형 실물 토큰 디자인으로 자동 변환됩니다.
이렇게 제작된 세상에 단 하나뿐인 디지털 유물 토큰을 온라인에서 1달러에 판매해 수익을 창출합니다.

## 🚀 시작하는 방법
1. 격리된 가상 환경을 생성하고 활성화합니다.
```bash
python -m venv venv
.\venv\Scripts\activate # Windows
source venv/bin/activate # macOS/Linux
```
2. 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```
3. (API 키 불필요 — 바로 실행됩니다!)
4. 스크립트를 실행합니다.
```bash
python code_dust_alchemist.py
```
