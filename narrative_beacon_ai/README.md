# 🚀 NarrativeBeacon AI: 세상에 없던 이야기를 찾아 떠나는 나침반



## ✨ 프로젝트 소개



NarrativeBeacon AI는 방대한 웹 콘텐츠 속에서 **'이야기 공백(Narrative Gaps)'**을 실시간으로 감시하는 혁신적인 AI 에이전트입니다. 특정 주제가 대중에게 과열되거나 식상해질 때, 아직 아무도 다루지 않은 **'숨겨진 서사 각도(Undiscovered Storyline Angles)'**를 포착하여 콘텐츠 크리에이터에게 알려줍니다.



이 프로젝트는 세상에 없던 신선한 이야기가 탄생할 수 있도록 **'미개척 스토리라인 지도'**를 제공하며, 궁극적으로는 이 지도를 1달러에 판매하여 창작의 새로운 지평을 열고자 합니다. 당신의 다음 위대한 이야기는 NarrativeBeacon AI와 함께 시작될 수 있습니다!



## 🌟 주요 기능



*   **과포화 서사 감지**: 특정 주제에 대한 흔하고 반복적인 서사 패턴(예: '성공', '혁신', '미래')을 식별하고 과열 정도를 알려줍니다.

*   **미개척 서사 발굴**: 대중에게 많이 알려지지 않았지만 잠재적으로 흥미로운 서사 각도(예: '도전', '윤리', '부작용', '인간')를 찾아내어 새로운 스토리라인 기회를 제시합니다.

*   **사용자 정의 분석**: 사용자가 제공하는 텍스트 파일과 특정 주제를 바탕으로 맞춤형 분석을 수행합니다.



## 🛠️ 시작하기: 초보자도 쉽게 따라 할 수 있어요!



이 프로젝트는 파이썬으로 작성되었으며, 별도의 외부 라이브러리 설치 없이 바로 실행할 수 있습니다.



### 📝 1단계: 코드 다운로드 및 준비



1.  이 소스코드 (`narrative_beacon_ai.py`)를 컴퓨터의 원하는 폴더에 저장하세요. 예를 들어, `my_projects`라는 폴더를 만들고 그 안에 파일을 저장할 수 있습니다.



    ```

    my_projects/

    └── narrative_beacon_ai.py

    ```



### 🐍 2단계: 파이썬 가상 환경 설정 (선택 사항이지만 권장!)



가상 환경은 프로젝트별로 독립적인 파이썬 작업 공간을 만들어 충돌을 방지합니다. 초보자도 쉽게 할 수 있습니다!



1.  **터미널(명령 프롬프트/PowerShell/bash) 열기**:

    *   **윈도우**: `Windows 키 + R`을 누르고 `cmd` 또는 `powershell`을 입력 후 엔터.

    *   **macOS/리눅스**: `Command + Space`를 누르고 `터미널` 검색 후 엔터.



2.  **프로젝트 폴더로 이동**: `cd` 명령어를 사용하여 `narrative_beacon_ai.py` 파일이 있는 폴더로 이동합니다.



    ```bash

    cd my_projects

    ```



3.  **가상 환경 생성**: 다음 명령어를 입력하여 `venv`라는 이름의 가상 환경을 만듭니다.



    ```bash

    python -m venv venv

    ```



4.  **가상 환경 활성화**:

    *   **윈도우**:

        ```bash

        .\venv\Scripts\activate

        ```

    *   **macOS/리눅스**:

        ```bash

        source venv/bin/activate

        ```

    가상 환경이 성공적으로 활성화되면 터미널 프롬프트 앞에 `(venv)`와 같은 표시가 나타납니다.



### 🚀 3단계: NarrativeBeacon AI 실행!



**🔔 중요: 이 프로젝트는 별도의 API 키나 환경 변수 설정이 필요 없습니다! 바로 실행할 수 있습니다.**



1.  **샘플 데이터로 실행 (가장 쉬운 방법!)**:

    어떤 옵션도 주지 않으면, 내장된 샘플 데이터를 사용하여 데모를 실행합니다.

    ```bash

    python narrative_beacon_ai.py

    ```



2.  **나만의 텍스트 파일로 분석하기**:

    분석하고 싶은 콘텐츠가 담긴 텍스트 파일(예: `my_articles.txt`)을 준비하세요. 각 줄마다 하나의 기사, 문단 또는 콘텐츠 조각을 넣어주세요.



    ```bash

    # 예시: my_articles.txt 파일 준비

    # 첫째 줄: AI 기술의 발전은 인류에게 새로운 성공의 가능성을 제시합니다.

    # 둘째 줄: 하지만 AI 윤리 문제와 인간의 일자리 감소에 대한 도전 과제도 간과할 수 없습니다.

    # ...

    ```



    파일 경로를 `--file` 인자로 지정하여 실행합니다:

    ```bash

    python narrative_beacon_ai.py --file my_articles.txt

    ```



3.  **분석할 주제 지정하기**:

    `--topic` 인자를 사용하여 분석의 핵심 주제를 변경할 수 있습니다. 기본값은 `'AI'`입니다.



    ```bash

    python narrative_beacon_ai.py --file my_articles.txt --topic 환경보호

    ```

    또는 샘플 데이터로 주제만 변경할 수도 있습니다:

    ```bash

    python narrative_beacon_ai.py --topic 경제위기

    ```



## 🔍 실행 결과 이해하기



스크립트를 실행하면 다음과 같은 출력을 볼 수 있습니다:



*   **`[NarrativeBeacon AI] 주제 '...'에 대한 콘텐츠 분석 시작...`**: 현재 분석 중인 주제를 알려줍니다.

*   **`인기 서사 패턴 분석: {'성공': 3, '혁신': 2, ...}`**: '성공', '혁신' 등 대중적인 키워드가 얼마나 언급되었는지 보여줍니다.

*   **`감지: 주제 '...'의 일반적인 서사각(...)이 과포화 상태입니다.`**: 대중적인 키워드 언급량이 일정 임계값(현재 코드에서는 5)을 넘으면 과포화로 판단합니다.

*   **`미개척 서사 각도 분석: {'도전': 2, '윤리': 1, ...}`**: '도전', '윤리' 등 비교적 덜 다루어지는 키워드가 얼마나 언급되었는지 보여줍니다.

*   **`발견: 다음은 탐색되지 않은 흥미로운 스토리라인 기회입니다: ['도전', '윤리']`**: 미개척 키워드 중 너무 흔하지 않으면서도(현재 코드에서는 언급 횟수 0 초과 3 미만) 의미 있는 스토리라인 기회를 제시합니다.



이 정보를 바탕으로 당신의 다음 콘텐츠 주제를 정하거나, 기존 주제에 대한 새로운 접근 방식을 찾을 수 있습니다.



## ⚠️ 경고 및 주의사항



*   **간소화된 AI 로직**: 현재 코드는 교육 및 시연 목적으로 매우 단순화된 키워드 기반 분석을 사용합니다. 실제 웹 콘텐츠 분석을 위해서는 고급 자연어 처리(NLP) 기술과 머신러닝 모델이 필요합니다.

*   **샘플 데이터 한계**: 내장된 샘플 데이터는 제한적입니다. 더 정확하고 의미 있는 분석을 위해서는 방대한 양의 실제 웹 콘텐츠를 담은 파일을 직접 제공해야 합니다.

*   **실행 환경 방어 코드**: 소스코드 상단에 있는 한글 윈도우 환경에서의 `UnicodeEncodeError` 방지 코드는 중요한 부분이므로 **절대 삭제하지 마세요.**



## 💡 향후 개선 방향 (아이디어)



*   **실시간 웹 크롤링 연동**: 특정 주제에 대한 최신 웹 콘텐츠를 실시간으로 수집하여 분석.

*   **고급 NLP 모델 적용**: 텍스트 임베딩, 토픽 모델링(LDA, NMF), 감성 분석 등을 활용하여 서사의 뉘앙스까지 파악.

*   **사용자 인터페이스(UI)**: 분석 결과를 시각화하고 스토리라인 지도를 탐색할 수 있는 웹 기반 또는 데스크톱 애플리케이션 개발.

*   **수익화 모델 고도화**: 발견된 '미개척 스토리라인 지도'를 구독형 또는 건별 판매 형태로 제공하는 플랫폼 구축.
