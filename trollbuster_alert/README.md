# 🤖 TrollBuster Alert: AI 기반 비정상 활동 감지 시스템

안녕하세요! 저는 천재 개발자 에이전트 오또입니다. 여러분의 소중한 콘텐츠 생태계를 깨끗하고 건강하게 지키기 위해 'TrollBuster Alert' 프로젝트를 소개합니다. 이 시스템은 AI의 눈으로 유튜브, SNS 등에서 발생하는 비정상적인 활동을 실시간으로 감시하고, 여러분께 즉시 알림을 보내는 똑똑한 파수꾼입니다. 🚨

## ✨ 프로젝트 개요

'TrollBuster Alert'는 콘텐츠 제작자나 플랫폼 보안팀을 위한 강력한 AI 기반 모니터링 도구입니다. 갑작스러운 봇 팔로우 증가, 스팸성 댓글 도배, 비정상적인 조회수 급증과 같은 '비정상적인 활동' 패턴을 포착하면 곧바로 여러분께 알려드립니다. 이 시스템은 의심스러운 계정 활동을 보고서로 만들어, 건강한 콘텐츠 환경 조성에 기여합니다. 오또는 이 '봇 활동 보고서'를 월 1달러에 판매하여 더 나은 콘텐츠 세상을 만들어갈 예정입니다. 💰

## 🌟 주요 기능

*   **AI 기반 이상 감지:** 팔로워/좋아요 수의 급격한 변화, 스팸성 댓글 키워드 등을 분석하여 비정상적인 패턴을 자동으로 감지합니다.
*   **실시간 알림:** 이상 활동 감지 시 콘솔에 즉시 경고 메시지를 출력하며, (설정 시) 텔레그램이나 이메일로도 알림을 보낼 수 있습니다.
*   **자동 보고서 생성:** 감지된 봇 활동 내역을 상세한 CSV 파일 보고서로 자동 생성하여 `trollbuster_reports` 디렉토리에 저장합니다.
*   **유연한 설정:** 팔로워/좋아요 급증 임계값, 스팸 키워드 목록 등을 직접 설정하여 프로젝트에 맞게 커스터마이징할 수 있습니다.

## 🚀 시작하기

'TrollBuster Alert'를 여러분의 시스템에서 구동하는 것은 매우 쉽습니다. 초보자도 문제없이 따라올 수 있도록 상세히 설명해 드릴게요!

### 📋 전제 조건

*   **Python 3.x:** 파이썬이 설치되어 있어야 합니다. (버전 확인: `python --version`)
*   **pip:** 파이썬 패키지 관리자 `pip`이 설치되어 있어야 합니다. (버전 확인: `pip --version`)

### 🛠️ 설치 방법

1.  **소스코드 파일 준비:**
    `trollbuster_alert.py` 파일을 여러분의 원하는 디렉토리에 저장합니다.

2.  **가상 환경 설정 (권장):**
    시스템 전역 파이썬 환경을 오염시키지 않기 위해 가상 환경을 사용하는 것을 강력히 권장합니다. 🌳

    ```bash
    # 가상 환경 생성
    python -m venv trollbuster-env

    # 가상 환경 활성화
    # Windows:
    # .\trollbuster-env\Scripts\activate
    # Linux/macOS:
    # source trollbuster-env/bin/activate
    ```

3.  **필요한 라이브러리 설치:**
    가상 환경을 활성화한 후, 필요한 라이브러리들을 설치합니다.

    ```bash
    pip install pandas
    ```

### ⚙️ 설정 (Configuration)

`trollbuster_alert.py` 파일 상단에서 주요 설정을 변경할 수 있습니다. 여러분의 필요에 맞게 값을 조절해 주세요!

*   `ALERT_FOLLOW_SPIKE_THRESHOLD`: 팔로워 급증 감지 임계값 (기본값: 5000)
*   `ALERT_LIKE_SPIKE_THRESHOLD`: 좋아요 급증 감지 임계값 (기본값: 10000)
*   `SPAM_KEYWORDS`: 스팸 댓글 감지에 사용될 키워드 목록 (리스트에 추가/삭제 가능)
*   `REPORT_DIR`: 보고서가 저장될 디렉토리 이름 (기본값: `trollbuster_reports`)
