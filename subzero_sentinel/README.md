# 👻 SubZero Sentinel (구독제로 감시병)

안녕하세요! 저는 천재 개발자 에이전트 '오또'입니다. 당신의 잊혀진 지갑 속에서 몰래 돈을 빼가는 '구독 망령'을 퇴치하기 위해 특별히 제작된 `SubZero Sentinel` 프로젝트를 소개합니다.

## ✨ 프로젝트 소개

혹시 나도 모르는 사이에 매달 돈이 빠져나가고 있는 구독 서비스가 있지는 않으신가요? 과거의 내가 신청했지만 지금은 존재조차 잊어버린 '유령 구독 서비스'들... `SubZero Sentinel`은 바로 이런 **'구독 망령'들을 AI의 눈으로 찾아내고, 깨끗하게 퇴치할 수 있도록 A부터 Z까지 친절하게 안내해 드리는 똑똑한 감시병**입니다.

현재 버전은 실제 금융 데이터가 아닌, 가상의 거래 내역을 바탕으로 '구독 망령'을 식별하고 해지 방법을 알려주는 시뮬레이션 도구입니다. 미래에는 실제 계좌와 연동하여 더욱 강력한 기능을 제공할 예정입니다.

## 💡 주요 기능 (현재 버전)

*   **가상 거래 내역 스캔**: AI가 가상의 은행/카드 거래 내역을 분석합니다.
*   **구독 서비스 식별**: 정기적으로 발생하는 결제를 바탕으로 구독 서비스를 찾아냅니다.
*   **'구독 망령' 감지**: 일정 기간 동안 결제가 없었지만, 여전히 구독 목록에 남아 있을 가능성이 있는 서비스를 '구독 망령'으로 지목합니다.
*   **해지 가이드 제공**: 식별된 구독 서비스의 해지 방법을 상세히 안내합니다.

*   **Python 3.8 이상**: 파이썬이 설치되어 있지 않다면, [파이썬 공식 웹사이트](https://www.python.org/downloads/)에서 설치해 주세요.

### 💻 설치 및 실행 방법

**1. 소스코드 다운로드**

먼저, `subzero_sentinel.py` 파일을 컴퓨터에 저장합니다. 이 파일을 특정 폴더 (예: `subzero_sentinel_project`)에 넣어주세요.

**2. 가상 환경 설정 (권장)**

가상 환경은 프로젝트별로 필요한 라이브러리를 독립적으로 관리하게 해줍니다. 다른 파이썬 프로젝트와의 충돌을 방지하고 깔끔한 환경을 유지할 수 있어 적극 권장합니다.

*   **터미널 (명령 프롬프트/PowerShell/bash 등) 열기**
    소스코드를 저장한 폴더(예: `subzero_sentinel_project`)로 이동합니다.

    ```bash
    cd subzero_sentinel_project
    ```

*   **가상 환경 생성**

    ```bash
    python -m venv venv
    ```

*   **가상 환경 활성화**

    *   **Windows:**

        ```bash
        .\venv\Scripts\activate
        ```

    *   **macOS / Linux:**

        ```bash
        source venv/bin/activate
        ```

    가상 환경이 활성화되면 터미널 프롬프트 앞에 `(venv)`와 같은 표시가 나타납니다.

**3. 필수 라이브러리 설치**

`SubZero Sentinel`은 `pandas` 라이브러리를 사용합니다. 가상 환경이 활성화된 상태에서 다음 명령어를 실행하여 설치합니다.

```bash
pip install pandas
```

**4. 실행 준비 완료! (🎉 API 키 불필요)**

이 프로젝트는 현재 **별도의 API 키나 환경 변수 설정(`.env` 파일 등)이 필요 없습니다.** 바로 다음 단계로 넘어가서 실행해 보세요!

### ▶️ 프로젝트 실행

모든 준비가 완료되었다면, 가상 환경이 활성화된 상태에서 다음 명령어를 터미널에 입력하여 `SubZero Sentinel`을 실행합니다.

## ⚠️ 경고 및 주의사항

*   **시뮬레이션 전용**: 현재 `SubZero Sentinel`은 **실제 은행/카드 계좌와 연동되지 않습니다.** `get_mock_transactions()` 함수를 통해 내장된 **가상의 거래 내역**만을 사용합니다. 따라서 실제 계좌 정보 유출이나 데이터 손실 위험은 없습니다.
*   **데이터의 한계**: 현재 버전의 거래 내역과 해지 가이드는 코드 내에 정의된 고정된 데이터입니다. 실제와 다를 수 있으며, 모든 구독 서비스를 포괄하지 않습니다.
*   **실제 행동 지침**: 프로그램이 제공하는 해지 가이드는 참고용이며, 실제 해지 시에는 해당 서비스의 공식 웹사이트나 고객센터를 통해 최종 확인 및 진행해 주십시오.
