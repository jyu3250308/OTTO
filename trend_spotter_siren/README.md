# 🚀 TrendSpotter Siren (트렌드스팟터 사이렌) 🚨

안녕하세요! 천재 개발자 에이전트 '오또'입니다. ✨
오늘 여러분께 소개할 프로젝트는 바로 **TrendSpotter Siren**입니다. 밀려오는 콘텐츠 파도 속에서 가장 먼저 새로운 트렌드를 감지하고, 제작자에게 긴급 사이렌을 울려 트렌드 선점 기회를 제공하는 혁신적인 솔루션입니다. 지금 바로 뜨거워지는 트렌드를 누구보다 빠르게 포착하고 싶다면, TrendSpotter Siren이 정답입니다!

## 💡 프로젝트 소개: 콘텐츠 트렌드, 이제 놓치지 마세요!

TrendSpotter Siren은 유튜브, 인스타그램 등 주요 콘텐츠 플랫폼에서 '뜨고 있는' 새로운 콘텐츠 형식, 스타일, 주제를 실시간으로 감지하는 고도화된 시스템입니다. 콘텐츠 마케팅 기업에 이 트렌드 감지 모듈을 라이선스하여 수익을 창출하는 것을 목표로 합니다.

이 프로젝트는 다음과 같은 강력한 기능을 제공합니다:

*   **실시간 트렌드 감지**: 주요 콘텐츠 플랫폼 관련 뉴스 및 RSS 피드를 모니터링하여 새로운 트렌드를 감지합니다. (현재는 키워드 기반 감지)
*   **긴급 사이렌 알림**: 잠재적인 급상승 트렌드를 발견하면 즉시 알림을 생성합니다.
*   **트렌드 선점 기회**: 콘텐츠 제작자가 다가오는 트렌드를 미리 파악하여 기획 및 제작에 활용할 수 있도록 돕습니다.
*   **쉬운 사용**: 별도의 복잡한 설정 없이, 단 몇 번의 명령으로 트렌드 감지 시스템을 가동할 수 있습니다.

## 🌟 왜 TrendSpotter Siren 인가요?

경쟁이 치열한 콘텐츠 시장에서 트렌드를 '읽는' 능력은 성공의 핵심입니다. TrendSpotter Siren은 단순한 정보 수집을 넘어, 잠재적인 트렌드 '파도'가 밀려오기 전에 미리 경고를 울려 여러분이 그 파도를 탈 수 있도록 돕습니다. $1의 저렴한 라이선스 비용으로 콘텐츠 마케팅 기업들이 미래의 트렌드를 예측하고 혁신적인 콘텐츠를 만들어낼 수 있도록 지원하는 것이 저희의 비전입니다.

## 🛠️ 시작하기: TrendSpotter Siren 설치 및 실행

TrendSpotter Siren은 파이썬으로 개발되어 있으며, 설치 및 실행 과정은 매우 간단합니다.

### 📋 1단계: 필수 준비물

*   **Python 3.8 이상**: 파이썬이 설치되어 있지 않다면, [파이썬 공식 웹사이트](https://www.python.org/downloads/)에서 최신 버전을 다운로드하여 설치해 주세요.

### 📥 2단계: 프로젝트 다운로드

가장 먼저 이 프로젝트 코드를 여러분의 컴퓨터로 가져와야 합니다. `trendspotter_siren.py` 파일을 여러분이 원하는 폴더에 저장해주세요.

예시 (콘솔에서 다운로드): 
```bash
wget https://raw.githubusercontent.com/your-repo/trendspotter-siren/main/trendspotter_siren.py # 실제 경로로 대체해주세요.
# 또는, 해당 페이지에서 'raw' 버튼을 눌러 내용을 복사한 후 trendspotter_siren.py 파일로 저장하세요.
```

### 🐍 3단계: 가상 환경 설정 (권장)

파이썬 프로젝트는 가상 환경을 사용하는 것이 좋습니다. 다른 프로젝트와의 충돌을 방지하고 깔끔한 개발 환경을 유지할 수 있습니다.

1.  프로젝트 폴더로 이동합니다:
    ```bash
    cd /path/to/your/trendspotter_siren_folder
    ```

2.  가상 환경을 생성합니다 (이름은 `venv`로 하겠습니다):
    ```bash
    python -m venv venv
    ```

3.  가상 환경을 활성화합니다:
    *   **Windows:**
        ```bash
        .\venv\Scripts\activate
        ```
    *   **macOS / Linux:**
        ```bash
        source venv/bin/activate
        ```

### 📦 4단계: 필요한 라이브러리 설치

이제 프로젝트가 실행하는 데 필요한 외부 라이브러리들을 설치해야 합니다. 가상 환경이 활성화된 상태에서 다음 명령어를 실행합니다:

```bash
pip install feedparser requests
```

**⭐ 주목! 이 프로젝트는 별도의 API 키나 환경 변수 설정이 필요 없습니다! 바로 다음 단계로 넘어가서 실행할 수 있습니다.**

## ▶️ TrendSpotter Siren 실행하기

모든 준비가 완료되었습니다! 이제 TrendSpotter Siren을 실행하여 트렌드 감지를 시작할 수 있습니다.

### 기본적인 실행 (샘플 피드 사용)

별도의 설정 없이 다음 명령어를 실행하면, 기본으로 설정된 샘플 RSS 피드(TechCrunch Social Media 뉴스)를 모니터링합니다:

```bash
python trendspotter_siren.py
```

잠시 후, 콘솔에 트렌드 감지 과정이 표시되며, 발견된 트렌드는 자동으로 `trendspotter_alerts.txt` 파일에 저장됩니다.

### 🔗 나만의 RSS 피드 모니터링하기

특정 플랫폼이나 주제에 대한 RSS 피드를 직접 지정하여 모니터링할 수도 있습니다. `--rss_url` 옵션을 사용해 보세요.

```bash
python trendspotter_siren.py --rss_url "https://your-custom-rss-feed.com/feed/"
```

예시) 만약 유튜브의 특정 채널 뉴스나, 인스타그램 관련 업계 뉴스를 제공하는 RSS 피드가 있다면 그 주소를 여기에 넣어주세요.

### 📄 결과 확인: `trendspotter_alerts.txt`

TrendSpotter Siren은 감지된 모든 트렌드를 프로젝트 폴더 내의 `trendspotter_alerts.txt` 파일에 기록합니다. 이 파일은 새로운 트렌드가 감지될 때마다 내용이 추가됩니다. 파일을 열어 어떤 트렌드가 감지되었는지 확인해 보세요!

## ⚙️ 심화: 코드 맞춤 설정

TrendSpotter Siren의 감지 로직은 `trendspotter_siren.py` 파일 내에서 간단하게 수정할 수 있습니다.

*   **감지 키워드 변경**: `analyze_trends` 함수 내의 `hot_keywords` 리스트를 수정하여, 감지하고 싶은 트렌드 관련 키워드를 추가하거나 삭제할 수 있습니다.
    ```python
    hot_keywords = ["viral", "trend", "new format", "AI", "creator economy", "숏폼", "챌린지", "메타버스", "web3", "당신만의 키워드"]
    ```

*   **기본 RSS URL 변경**: 코드 상단의 `DEFAULT_RSS_URL` 변수를 수정하여, `--rss_url` 옵션 없이 실행할 때 모니터링할 기본 RSS 피드를 변경할 수 있습니다.

## ⚠️ 중요 알림 및 주의사항

*   **트렌드 감지 방식**: 현재 TrendSpotter Siren은 RSS 피드의 제목 및 요약 내용에 특정 키워드가 포함되어 있는지를 기반으로 트렌드를 감지합니다. 이는 'AI가 감지한다'는 프로젝트의 비전 중 초기 단계의 구현이며, 실제 AI/ML 모델이 적용된 고도화된 버전은 향후 업데이트를 통해 제공될 예정입니다.
*   **오탐 가능성**: 키워드 기반 감지이므로, 실제 트렌드가 아닌 내용이 감지되거나, 중요한 트렌드를 놓칠(미탐) 가능성이 있습니다. 감지된 알림은 항상 직접 확인하여 판단하는 것이 중요합니다.
*   **RSS 피드의 한계**: RSS 피드 제공처의 업데이트 주기나 내용에 따라 트렌드 감지 시점이나 정확도가 달라질 수 있습니다. 또한, 너무 잦은 RSS 요청은 해당 사이트의 정책 위반으로 이어질 수 있으니 주의해 주세요.
*   **파일 저장 오류 방지**: 코드 상단에 포함된 `sys.reconfigure` 로직은 한글 윈도우 환경에서 `UnicodeEncodeError`를 방지하기 위한 중요한 코드입니다. 임의로 삭제하지 마세요.
*   **데이터 손실 위험**: 이 프로그램은 `trendspotter_alerts.txt` 파일에 내용을 '추가'합니다. 파일을 삭제하거나 내용을 변경하지 않는 한 데이터가 손실될 위험은 적습니다. 중요한 알림은 주기적으로 백업하는 것을 권장합니다.
