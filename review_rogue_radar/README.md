# Review Rogue Radar: 짭리뷰 냄새 맡는 AI 탐정 🕵️‍♀️

## 🚀 프로젝트 소개
'Review Rogue Radar'는 온라인 쇼핑몰 및 커뮤니티의 상품 리뷰에서 **'수상한 냄새'**를 풍기는 패턴을 발굴하는 AI 기반 탐지 시스템입니다. 단순히 리뷰의 긍정/부정 여부를 판단하는 것을 넘어, 특정 상품군에서 반복되는 문체, 키워드, 시간 패턴 등을 분석하여 진짜 리뷰와 조작된 리뷰 사이의 미묘한 경계를 파헤칩니다.

이렇게 탐지된 **'리뷰 조작의 지문'**은 마케팅 분석가들에게 유료(1달러)로 판매되어, 시장의 투명성을 높이고 소비자들이 더욱 신뢰할 수 있는 정보를 얻을 수 있도록 돕는 것을 목표로 합니다. 본 프로젝트는 이러한 탐지 로직의 개념을 입증하기 위한 초기 단계의 파이썬 스크립트입니다.

## ✨ 주요 기능
*   **리뷰 데이터 모의 시뮬레이션**: 실제 리뷰 데이터를 모방한 더미 데이터를 사용하여 탐지 로직을 테스트합니다.
*   **수상한 키워드 탐지**: 특정 상품군에서 자주 사용되는 조작 의심 키워드(`"정말 최고"`, `"강력 추천"`, `"인생템"`, `"꼭 사세요"`, `"환상적인"`)를 식별합니다.
*   **시간 근접성 및 내용 유사성 분석**: 짧은 시간 내에 여러 사용자가 유사한 내용의 리뷰를 작성하는 패턴을 찾아냅니다. (예: 30분 이내에 동일 상품에 대한 리뷰 중 3개 이상의 공통 단어가 있는 경우)
*   **의심 리뷰 보고서 생성**: 탐지된 수상한 리뷰들을 정리하여 CSV 파일 (`rogue_reports.csv`)로 저장합니다.

    (🚨 실행 후 터미널에 별다른 출력이 없을 수 있습니다. 모든 결과는 `rogue_reports.csv` 파일에 저장됩니다.)

## 📊 결과 파일: `rogue_reports.csv`

`rogue_reports.csv` 파일은 다음과 같은 형식으로 의심 리뷰에 대한 상세 정보를 제공합니다.

| 컬럼 명      | 설명                                                      |
| :----------- | :-------------------------------------------------------- |
| `review_id`  | 의심스러운 리뷰의 고유 ID                                 |
| `product_id` | 리뷰가 작성된 상품의 고유 ID                              |
| `user_id`    | 리뷰를 작성한 사용자의 고유 ID                            |
| `timestamp`  | 리뷰 작성 시간                                            |
| `content`    | 리뷰 내용                                                 |
| `rating`     | 리뷰 평점 (1~5)                                           |
| `reasons`    | 이 리뷰가 의심스러운 이유 (키워드, 시간 근접성 등)        |

**예시:**
```csv
review_id,product_id,user_id,timestamp,content,rating,reasons
R001,P101,U001,2023-10-26 10:00:00,"정말 최고에요! 이 제품은 제 인생템입니다. 강력 추천해요.",5,"키워드: '정말 최고',키워드: '강력 추천',키워드: '인생템'"
R002,P101,U002,2023-10-26 10:05:00,"최고의 선택이었어요. 정말 좋아요. 꼭 사세요!",5,"키워드: '꼭 사세요',시간 근접성 및 유사한 내용"
R005,P101,U005,2023-10-26 10:15:00,"강력 추천합니다. 이 가격에 이 품질이라니 놀라워요. 정말 최고.",5,"키워드: '강력 추천',키워드: '정말 최고',시간 근접성 및 유사한 내용"
R007,P101,U007,2023-10-26 10:20:00,"환상적인 제품! 꼭 사세요! 후회하지 않을 거예요. 인생템입니다.",5,"키워드: '환상적인',키워드: '꼭 사세요',키워드: '인생템',시간 근접성 및 유사한 내용"
```

## ⚠️ 중요 사항 및 경고
*   **모의 데이터 사용**: 현재 버전은 `MOCK_REVIEWS`라는 예시 데이터를 사용하여 작동합니다. 실제 환경에서 사용하려면 온라인 쇼핑몰 등에서 리뷰 데이터를 수집하는 로직이 추가되어야 합니다.
*   **초기 AI 로직**: 본 스크립트의 AI 탐지 로직은 간단한 키워드 매칭 및 시간/내용 유사성 분석을 기반으로 합니다. 실제 조작된 리뷰를 완벽하게 잡아내기 위해서는 더 고도화된 자연어 처리(NLP), 머신러닝 모델, 사용자 행동 분석 등이 필요합니다.
*   **데이터 손실 위험 없음**: 이 스크립트는 기존 파일을 수정하지 않고 새로운 `rogue_reports.csv` 파일을 생성합니다. 따라서 원본 데이터 손실의 위험은 없습니다.
*   **API 사용 제한 없음**: 외부 API를 전혀 사용하지 않으므로, API 사용량 제한이나 비용 발생에 대한 걱정 없이 자유롭게 사용할 수 있습니다.
*   **오탐 가능성**: 현재 로직은 '수상한' 패턴을 발견하는 데 초점을 맞추므로, 실제로는 조작이 아닌 정상적인 리뷰를 오탐(false positive)할 가능성도 있습니다. 결과는 '참고 자료'로 활용하고, 실제 판단 시에는 전문가의 검토가 필요합니다.
