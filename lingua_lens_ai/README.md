## 🛠️ 시작하기

이 프로젝트는 파이썬으로 개발되었으며, 별도의 복잡한 설치 과정 없이 바로 실행할 수 있습니다.

### 📋 전제 조건

*   **Python 3.7+**: 이 프로젝트는 Python 3 환경에서 동작합니다. 터미널(명령 프롬프트)에서 `python --version` 또는 `python3 --version` 명령어를 입력하여 파이썬 설치 여부 및 버전을 확인할 수 있습니다.

### 📦 설치 및 실행 방법

1.  **소스코드 파일 저장**: `lingua_lens_ai.py` 파일을 여러분의 컴퓨터에 저장합니다. 예시) `C:\projects\lingua_lens_ai.py`

2.  **터미널(명령 프롬프트) 열기**: 
    *   Windows: `Win + R`을 누른 후 `cmd` 입력 후 Enter.
    *   macOS/Linux: `Terminal` 앱 실행.

3.  **파일이 저장된 디렉토리로 이동**: `cd` 명령어를 사용하여 `lingua_lens_ai.py` 파일이 있는 폴더로 이동합니다.
    ```bash
    cd C:\projects  # Windows 예시
    # 또는
    cd ~/Desktop/lingua_lens_ai  # macOS/Linux 예시 (파일을 Desktop/lingua_lens_ai 폴더에 저장했을 경우)
    ```

4.  **가상 환경 설정 (선택 사항이지만 권장)**:
    *   파이썬 프로젝트를 관리할 때 가상 환경을 사용하는 것은 좋은 습관입니다. 이는 시스템 파이썬 환경과의 충돌을 방지합니다.
    ```bash
    python -m venv venv           # 가상 환경 생성
    # Windows:
    .\venv\Scripts\activate      # 가상 환경 활성화
    # macOS/Linux:
    source venv/bin/activate      # 가상 환경 활성화
    ```
    *   `deactivate` 명령어로 가상 환경을 비활성화할 수 있습니다.

5.  **프로젝트 실행**: 
    *   **이 프로젝트는 별도의 API 키나 `.env` 설정 파일이 필요 없습니다!** 바로 실행하시면 됩니다. 😊
    ```bash
    python lingua_lens_ai.py
    ```

6.  **결과 확인**: 
    *   스크립트 실행이 완료되면, 현재 실행 디렉토리 안에 자동으로 `reports` 폴더가 생성됩니다. 이 폴더 안에 `lingua_lens_report_오또_learner_001_YYYYMMDD_HHMMSS.html` 형태의 HTML 보고서 파일이 저장됩니다. 이 파일을 웹 브라우저로 열어 상세한 진단 및 처방 내용을 확인해 보세요!

## ⚠️ 중요 사항 및 주의사항

*   **모의(Mocking) 데이터 및 AI**: 현재 버전은 실제 사용자 데이터베이스나 외부 API와 연동되어 있지 않습니다. 코드 내에 포함된 `simulate_user_data()` 함수를 통해 가상 학습 데이터를 생성하며, `analyze_learning_data()` 함수는 미리 정의된 규칙에 따라 작동하는 **규칙 기반 AI (Mocking)** 로직입니다. 즉, 실제 최신 AI/머신러닝 모델을 활용한 분석이 아님을 이해해 주시기 바랍니다.
*   **데이터 지속성**: 현재는 데이터를 저장하는 기능이 없습니다. 스크립트를 재실행할 때마다 새로운 가상 데이터로 분석이 이루어집니다.
*   **보고서 출력**: 보고서는 `reports` 디렉토리에 생성됩니다. 같은 사용자 ID로 여러 번 실행하면 새로운 보고서가 생성되지만, 파일명에 타임스탬프가 포함되어 이전 보고서가 덮어씌워질 염려는 없습니다.
*   **한글 인코딩**: 윈도우 환경에서 발생할 수 있는 한글 출력 오류를 방지하기 위한 코드가 내장되어 있어, 안정적인 출력을 보장합니다.
