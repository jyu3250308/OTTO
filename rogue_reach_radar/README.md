# 🚀 Rogue Reach Radar: 비정상 노출 감시병

당신의 소중한 콘텐츠, 이제 AI가 지켜드립니다! 🕵️‍♀️

## 💡 프로젝트 소개

`Rogue Reach Radar`는 콘텐츠 제작자들이 겪는 '도달률 급락'이나 '비정상적 참여 패턴' 문제를 해결하기 위해 탄생했습니다. 플랫폼 알고리즘 변화, 섀도우밴(Shadowban) 등 예측하기 어려운 문제로 인해 콘텐츠가 묻히는 것을 방지하고자, AI가 실시간으로 당신의 SNS 게시물 데이터를 감시합니다. 잠재적인 문제를 감지하는 즉시 경고하여, 제작자가 빠르게 대응하고 소중한 노력이 헛되지 않도록 돕습니다.

더 나아가, 우리는 이 과정에서 얻은 **익명화된 '플랫폼 행동 메타데이터'를 외부 연구자에게 판매하여 $1의 수익**을 창출합니다. 이 데이터는 소셜 미디어 생태계 연구에 귀중한 자료로 활용될 것입니다.

## ✨ 주요 기능

*   **실시간 도달률 감시:** 게시물의 도달률이 이전 게시물 평균 대비 급격히 하락하는지 실시간으로 모니터링합니다.
*   **비정상 참여 패턴 감지:** 좋아요, 댓글 등 참여 지표의 이상 징후를 탐지합니다.
*   **유연한 임계치 설정:** 비정상 감지 기준(임계치)을 프로젝트 설정에서 직접 조정할 수 있습니다.
*   **자동 알림 시스템:** Slack 또는 Discord 웹훅을 통해 이상 징후 발생 시 즉시 알림을 발송합니다.
*   **상세 보고서 생성:** 탐지된 이상 징후에 대한 상세 보고서를 파일로 저장합니다.
*   **익명화된 메타데이터 수집:** 플랫폼 행동 메타데이터를 익명으로 수집하여 연구용으로 활용하고, 이 과정에서 $1의 수익을 창출합니다.

## 🛠️ 설치 및 실행 방법

`Rogue Reach Radar`를 구동하기 위한 단계별 안내입니다. 초보자도 쉽게 따라 할 수 있도록 상세히 설명합니다.

### 1. 전제 조건

*   **Python 3.8 이상:** 프로젝트는 Python 3 환경에서 개발되었습니다.

### 2. 프로젝트 클론 및 이동

먼저, 이 프로젝트의 소스코드를 다운로드합니다.

```bash
git clone https://github.com/your-username/rogue-reach-radar.git
cd rogue-reach-radar
```

### 3. 가상 환경 설정 (권장)

시스템 전체 Python 환경과의 충돌을 피하기 위해 가상 환경을 사용하는 것을 강력히 권장합니다.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate
```

가상 환경을 비활성화하려면 `deactivate` 명령을 사용하세요.

### 4. 필수 라이브러리 설치

현재 이 프로젝트는 Python 기본 라이브러리만을 사용하므로 별도의 `requirements.txt` 파일이 필요하지 않습니다. 하지만 향후 확장성을 위해 다음 명령을 미리 수행할 수 있습니다 (현재는 아무것도 설치되지 않습니다).

```bash
# 이 프로젝트는 현재 외부 라이브러리가 필요 없습니다.
# 향후 확장을 위해 미리 준비하는 차원에서 README에 포함합니다.
pip install -r requirements.txt
```

### 5. 데이터 준비 (CSV 파일)

`Rogue Reach Radar`는 CSV 형식의 게시물 데이터를 분석합니다. 분석을 시작하기 전에 다음과 같은 형식의 CSV 파일을 준비해야 합니다.

| `post_id` | `timestamp`         | `platform`  | `reach` | `likes` | `comments` |
| :-------- | :------------------ | :---------- | :------ | :------ | :--------- |
| p001      | 2023-10-01 10:00:00 | Instagram   | 1200    | 150     | 20         |
| p002      | 2023-10-02 11:00:00 | Instagram   | 1150    | 145     | 22         |
| p003      | 2023-10-03 12:00:00 | Instagram   | 1300    | 160     | 25         |
| ...       | ...                 | ...         | ...     | ...     | ...        |

*   **`post_id`**: 게시물 고유 ID (문자열)
*   **`timestamp`**: 게시물 작성 시간 (YYYY-MM-DD HH:MM:SS 형식의 문자열)
*   **`platform`**: 게시물이 올라온 플랫폼 (예: Instagram, Facebook 등)
*   **`reach`**: 게시물의 도달률 (정수)
*   **`likes`**: 게시물 '좋아요' 수 (정수)
*   **`comments`**: 게시물 댓글 수 (정수)

CSV 파일은 `UTF-8` 인코딩으로 저장되어야 합니다.
