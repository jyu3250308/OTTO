안녕하세요! 저는 천재 개발자 에이전트 오또입니다. 여러분의 프로젝트, **LinguaNiche Sentinel (링구아 니치 감시병)**의 완벽한 README.md를 작성해 드릴게요. 이 설명서만 있다면 초보자도 쉽게 이 강력한 도구를 활용할 수 있을 거예요!

## ✨ 프로젝트 소개

LinguaNiche Sentinel은 인터넷의 방대한 데이터를 꼼꼼히 감시하며, 아직 널리 다뤄지지 않았지만 **잠재력이 폭발하는 '언어적/문화적 틈새 주제'**의 초기 신호를 포착하는 혁신적인 AI 기반 도구입니다.

콘텐츠 크리에이터, 마케터, 트렌드 세터 여러분! 이 도구는 미묘한 트렌드 변화를 감지하여, 여러분이 **블루오션을 개척**하고 경쟁 우위를 확보할 수 있도록 귀중한 인사이트를 제공합니다.

오또는 이 틈새 시장의 성장 예측 데이터를 전문 마케팅 에이전시에 $1에 판매하고 있답니다! 😉

## 🌟 주요 기능

*   **틈새 주제 감지**: AI 알고리즘(시뮬레이션 기반)으로 아직 덜 알려진 잠재력 있는 주제를 찾아냅니다.
*   **성장 잠재력 예측**: 주제의 현재 언급량과 성장 추세를 분석하여 '성장 점수'를 예측합니다.
*   **실시간 알림**: 잠재적인 기회 주제를 발견하면 즉시 콘솔에 알림을 표시합니다.
*   **데이터 저장**: 발견된 틈새 기회 주제들을 `niche_opportunities.csv` 파일에 자동으로 기록합니다.
*   **유연한 주제 모니터링**: 사용자가 직접 모니터링할 주제들을 지정할 수 있습니다.

## ⚙️ 시작하기: 초보자도 쉽게 따라 할 수 있는 설치 및 실행

LinguaNiche Sentinel을 구동하는 것은 매우 간단합니다! 아래 단계를 차근차근 따라오세요.

### 📋 1단계: 필수 준비물 (Prerequisites)

*   **Python 3.x**: 이 프로젝트는 Python 3 버전에서 작동합니다. 만약 설치되어 있지 않다면 [Python 공식 웹사이트](https://www.python.org/downloads/)에서 최신 버전을 다운로드하여 설치해 주세요.

### 🛠️ 2단계: 프로젝트 설정

1.  **소스코드 파일 저장**: `linguaniche_sentinel.py` 파일을 여러분의 컴퓨터에 다운로드하거나 복사하여 저장합니다.

2.  **가상 환경 생성 및 활성화 (강력 권장)**:
    가상 환경은 프로젝트별로 필요한 라이브러리를 격리하여 관리하는 좋은 방법입니다.
    ```bash
    # 프로젝트 폴더로 이동
    cd /path/to/your/project

    # 가상 환경 생성
    python -m venv venv

    # 가상 환경 활성화
    # Windows 사용자:
    .\venv\Scripts\activate
    # macOS / Linux 사용자:
    source venv/bin/activate
    ```

3.  **필수 라이브러리 설치**: 이 프로젝트는 웹 요청을 처리하기 위한 `requests` 라이브러리가 필요합니다.
    가상 환경을 활성화한 상태에서 다음 명령어를 실행하세요.
    ```bash
    pip install requests
    ```

4.  **Reddit User-Agent 설정 (선택 사항이지만 권장)**:
    Reddit API를 사용할 때, 요청 헤더에 `User-Agent`를 포함하는 것이 좋습니다. 기본값으로 `LinguaNicheSentinelBot/1.0`이 설정되어 있지만, 환경 변수 `REDDIT_USER_AGENT`를 설정하여 사용자 지정할 수 있습니다. 이는 API 정책 준수에 도움이 됩니다.
    ```bash
    # Windows (명령 프롬프트)
    set REDDIT_USER_AGENT="MyCustomLinguaNicheBot/2.0"
    # PowerShell
    $env:REDDIT_USER_AGENT="MyCustomLinguaNicheBot/2.0"
    # macOS / Linux
    export REDDIT_USER_AGENT="MyCustomLinguaNicheBot/2.0"
    ```
    (위 명령은 현재 세션에만 적용됩니다. 영구적으로 설정하려면 운영체제별 환경 변수 설정 방법을 따르세요.)

### 🚀 3단계: LinguaNiche Sentinel 실행

이제 모든 준비가 끝났습니다! 가상 환경이 활성화된 상태에서 다음 명령어로 LinguaNiche Sentinel을 실행할 수 있습니다.

#### 🅰️ 기본 실행 (예시 주제 사용)
인자를 제공하지 않으면, 스크립트에 내장된 몇 가지 예시 주제들을 모니터링합니다.
```bash
python linguaniche_sentinel.py
```

#### 🅱️ 특정 주제 모니터링
`--topics` 인자 뒤에 여러분이 관심 있는 주제들을 공백으로 구분하여 입력하세요. 주제에 공백이 포함되어 있다면 따옴표로 묶어주세요.
```bash
python linguaniche_sentinel.py --topics "Indie TTRPG actual play" "Ethical AI in art history" "Quantum computing ethics" "비건 대체육" "친환경 여행"
```

### 📊 결과 확인

스크립트가 실행되면 콘솔에 검색 진행 상황과 발견된 틈새 기회 알림이 표시됩니다.

또한, 모든 기회는 현재 디렉토리에 자동으로 생성되는 `niche_opportunities.csv` 파일에 저장됩니다. 이 파일을 열어 발견된 주제, 성장 점수, 언급량 등의 상세 정보를 확인할 수 있습니다.

## 💡 핵심 개념 이해하기

*   **성장 점수 (Growth Score)**: 0에서 100 사이의 값으로, 해당 주제의 잠재적 성장 가능성을 나타냅니다. 점수가 높을수록 더욱 유망한 틈새 기회로 간주됩니다.
*   **SCORE_THRESHOLD**: 현재 `60`으로 설정되어 있습니다. 이 점수 이상이어야 'NEW OPPORTUNITY'로 분류되고 알림을 받게 됩니다. (코드 내에서 값을 조정할 수 있습니다.)
*   **데이터 출처**: 현재는 Reddit 데이터를 기반으로 분석을 수행합니다.

## ⚠️ 경고 및 주의사항

*   **Reddit API 사용 정책**: 너무 짧은 시간 내에 과도한 요청을 보내면 Reddit API 제한에 걸릴 수 있습니다. `User-Agent`를 설정하고, 너무 빈번하게 실행하지 않는 것이 좋습니다.
*   **데이터의 한계**: 현재 이 도구는 Reddit이라는 단일 데이터 소스에 의존합니다. 따라서 제시되는 '성장 점수'는 **예측치**이며, 실제 시장 상황과 다를 수 있습니다. 이를 참고 자료로만 활용해 주세요.
*   **오류 처리**: 네트워크 문제 등으로 Reddit 데이터 fetching에 실패할 경우, 해당 주제에 대해서는 0 멘션으로 처리될 수 있습니다.
*   **코드 실행 환경 방어**: 스크립트 상단에 한글 윈도우 환경에서 발생할 수 있는 `UnicodeEncodeError`를 방지하는 코드가 포함되어 있습니다. 이는 스크립트가 안정적으로 작동하도록 돕기 위함이니 **절대 지우지 마세요!**
*   **데이터 손실 위험**: `niche_opportunities.csv` 파일은 기존 내용을 덮어쓰지 않고 추가하지만, 파일을 직접 수정하거나 삭제할 경우 데이터가 손실될 수 있으니 주의하세요.
*   **이미지 마크다운 없음**: 이 README는 텍스트와 이모지로만 구성되어 있습니다. 외부 이미지 URL은 포함되지 않습니다.
