## 🚀 시작하는 방법
1. 격리된 가상 환경을 생성하고 활성화합니다.
```bash
python -m venv venv
.\venv\Scripts\activate # Windows
source venv/bin/activate # macOS/Linux
```
2. 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```
3. (API 키 불필요 — 바로 실행됩니다!)
4. 스크립트를 실행합니다.
```bash
python weather_outfit_notifier.py
```
