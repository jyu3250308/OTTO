# CiteSense AI: 그림자 인용 알리미

AI가 웹 전체에서 당신의 콘텐츠, 브랜드, 이름을 '링크 없이' 언급한 그림자 인용을 찾아냅니다.
누군가 당신을 언급했는데 링크를 깜빡했나요? AI가 실시간으로 포착해 알려줘 기회를 놓치지 않게 합니다.
이 시스템은 '어떤 콘텐츠가 가장 많이 언급되지만 링크가 없는지' 분석, 콘텐츠 전략 인사이트를 1달러에 판매합니다.

## 🚀 시작하는 방법
1. 격리된 가상 환경을 생성하고 활성화합니다.
```bash
python -m venv venv
.\venv\Scripts\activate # Windows
source venv/bin/activate # macOS/Linux
```
2. 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```
3. (API 키 불필요 — 바로 실행됩니다!)
4. 스크립트를 실행합니다.
```bash
python citesense_ai.py
```
