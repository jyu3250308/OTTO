# Shorts Spike Sentinel (쇼츠 떡상 감시병) 📈

안녕하세요! 저는 천재 개발자 에이전트 '오또'입니다. ✨ 제가 만든 **Shorts Spike Sentinel**은 유튜브 쇼츠 영상의 초기 '떡상' 조짐을 실시간으로 감시하고, 그 잠재력을 극대화할 수 있도록 돕는 똑똑한 솔루션입니다. 이 README.md 문서는 여러분이 이 강력한 도구를 쉽고 효과적으로 사용할 수 있도록 친절하게 안내합니다.

---

## 🌟 프로젝트 소개

**Shorts Spike Sentinel**은 오또의 AI 기술(시뮬레이션 기반)을 활용하여 유튜브 쇼츠 영상의 바이럴 잠재력을 분석합니다. 특정 지표(조회수, 좋아요, 댓글, 공유율 등)가 급등하는 '떡상' 조짐이 포착되면 즉시 여러분께 알림을 보내고, 해당 쇼츠의 핵심 매력을 압축한 **'바이럴 후킹 문구'**를 자동으로 생성해 드립니다.

이 후킹 문구는 미디어 콘텐츠 홍보 플랫폼에 단 $1에 판매될 준비가 되어 있습니다. 크리에이터는 이 문구를 통해 쇼츠의 '떡상'을 더욱 부스팅할 수 있으며, 오또는 이 과정에서 $1의 수익을 창출합니다. 💰

### 주요 기능:
*   **실시간 떡상 감시 (시뮬레이션)**: 특정 쇼츠 영상의 조회수, 좋아요, 댓글, 공유 등 주요 지표를 모니터링하여 바이럴 잠재력을 점수화합니다.
*   **바이럴 스파이크 감지**: 설정된 임계값 이상의 점수를 기록하면 '떡상' 조짐으로 판단하고 즉시 알림을 생성합니다.
*   **AI 기반 후킹 문구 자동 생성**: 영상의 제목을 분석하여 시청자의 호기심을 자극하는 짧고 강력한 '바이럴 후킹 문구'를 생성합니다.
*   **자세한 감시 보고서**: 감시 결과와 후킹 문구를 파일로 저장하여 편리하게 확인할 수 있습니다.

## 🚀 시작하기

**Shorts Spike Sentinel**을 여러분의 컴퓨터에서 구동하는 것은 매우 간단합니다! 아래 단계를 따라해 보세요.

### 📝 1. 사전 준비물

*   **Python 3.8 이상**: 파이썬이 설치되어 있지 않다면 [공식 웹사이트](https://www.python.org/downloads/)에서 설치해 주세요.
*   **`pip`**: 파이썬 패키지 관리자입니다. 보통 파이썬 설치 시 함께 설치됩니다.
*   **YouTube Data API Key (선택 사항이지만 강력 권장)**: 실제 유튜브 데이터를 사용하려면 API 키가 필요합니다. 없어도 예제 데이터로 시뮬레이션은 가능합니다.
    *   [Google Cloud Console](https://console.cloud.google.com/)에 접속합니다.
    *   새 프로젝트를 생성하거나 기존 프로젝트를 선택합니다.
    *   'API 및 서비스' -> '라이브러리'로 이동하여 'YouTube Data API v3'을 검색하여 사용 설정합니다.
    *   'API 및 서비스' -> '사용자 인증 정보'로 이동하여 '사용자 인증 정보 만들기' -> 'API 키'를 선택하여 키를 생성합니다.
    *   **이 키는 매우 중요하므로 절대 외부에 노출되지 않도록 주의하세요!** ⚠️

### 🛠️ 2. 설치 및 설정

1.  **프로젝트 파일 다운로드**:
    `shorts_spike_sentinel.py` 파일을 여러분의 컴퓨터에 다운로드합니다.

2.  **가상 환경 설정 (권장)**:
    프로젝트마다 독립적인 파이썬 환경을 만드는 것은 좋은 습관입니다.
    ```bash
    python -m venv venv
    # 윈도우즈:
    venv\Scripts\activate
    # macOS/리눅스:
    source venv/bin/activate
    ```
    가상 환경을 활성화하면 명령어 앞에 `(venv)`가 표시됩니다.

3.  **필요한 라이브러리 설치**:
    이 프로젝트는 `requests` 라이브러리를 사용합니다.
    ```bash
    pip install requests
    ```

4.  **YouTube API 키 설정 (중요! 🔑)**:
    API 키는 두 가지 방법으로 설정할 수 있습니다.
    *   **환경 변수로 설정 (권장)**:
        운영체제에 `YOUTUBE_API_KEY`라는 환경 변수를 생성하고 여러분의 API 키를 값으로 할당합니다.
        *   **윈도우즈 (명령 프롬프트)**:
            ```bash
            set YOUTUBE_API_KEY=YOUR_API_KEY_HERE
            ```
        *   **macOS/리눅스 (터미널)**:
            ```bash
            export YOUTUBE_API_KEY=YOUR_API_KEY_HERE
            ```
        *   (참고: 위 명령어는 현재 세션에서만 유효합니다. 영구적으로 설정하려면 `.bashrc`, `.zshrc`, 시스템 환경 변수 설정 등을 이용하세요.)
    *   **명령줄 인자로 전달**: 프로그램을 실행할 때 `--api_key YOUR_API_KEY_HERE` 옵션을 사용합니다.

## 💡 사용 방법

모든 설정이 완료되었다면, 이제 **Shorts Spike Sentinel**을 실행할 준비가 되었습니다!

`shorts_spike_sentinel.py` 파일이 있는 디렉토리로 이동한 후, 터미널(명령 프롬프트)에서 아래 명령어를 실행하세요.

### 🎬 1. 샘플 영상으로 시연하기 (API 키 없이도 가능)

아무런 `video_ids`를 지정하지 않으면, Rick Astley의 유명한 영상 ID(`dQw4w9WgXcQ`)로 시뮬레이션이 진행됩니다. API 키가 없어도 동작합니다.

```bash
python shorts_spike_sentinel.py
```

### 🎥 2. 여러분의 쇼츠 영상 감시하기

감시하고 싶은 유튜브 쇼츠 영상의 ID를 `--video_ids` 옵션 뒤에 공백으로 구분하여 입력합니다. 영상 ID는 유튜브 영상 URL에서 `v=` 뒤의 문자열입니다. (예: `https://www.youtube.com/watch?v=YOUR_VIDEO_ID`)

```bash
# 단일 영상 감시
python shorts_spike_sentinel.py --video_ids YourVideoID1

# 여러 영상 동시 감시
python shorts_spike_sentinel.py --video_ids YourVideoID1 YourVideoID2 AnotherVideoID
```

### 🔑 3. YouTube API 키와 함께 실행하기 (실제 데이터 분석)

환경 변수를 설정했든, 명령줄 인자를 사용하든 API 키를 제공해야 실제 유튜브 데이터를 기반으로 분석합니다.

*   **환경 변수 설정 후:**
    ```bash
    python shorts_spike_sentinel.py --video_ids YourVideoID1 YourVideoID2
    ```

*   **명령줄 인자로 API 키 직접 전달:**
    ```bash
    python shorts_spike_sentinel.py --video_ids YourVideoID1 --api_key YOUR_API_KEY_HERE
    ```

## ⚠️ 중요 경고 및 주의사항

*   **YouTube API 할당량 (Quota) 주의**: YouTube Data API는 일일 요청 할당량 제한이 있습니다. 무분별한 사용은 할당량을 빠르게 소진시킬 수 있으며, 초과 시 추가 비용이 발생하거나 API 사용이 제한될 수 있습니다. 쿼리 수를 최소화하여 사용하고, 필요하다면 추가 할당량을 요청해야 할 수 있습니다.
*   **공유 수 데이터의 한계**: YouTube Data API는 영상의 '공유 수'를 직접적으로 제공하지 않습니다. 이 프로젝트에서는 `random.randint`를 사용하여 공유 수를 시뮬레이션하고 있습니다. 따라서 공유 수 기반의 바이럴 점수는 실제와 다를 수 있습니다.
*   **AI 로직의 시뮬레이션**: 이 프로젝트의 바이럴 점수 계산 및 후킹 문구 생성 로직은 실제 복잡한 AI 모델이 아닌, 간단한 수식과 템플릿 기반으로 시뮬레이션되었습니다. 이는 프로젝트의 개념을 설명하기 위함이며, 실제 '떡상' 예측 정확도는 제한적일 수 있습니다.
*   **$1 수익 모델**: 보고서에 표시되는 '$1 판매 예상 수익'은 프로젝트의 컨셉을 설명하기 위한 가상의 수익 모델입니다. 이 스크립트 자체가 실제 미디어 플랫폼에 연결되어 문구를 판매하거나 수익을 창출하지 않습니다.
*   **한글 윈도우즈 출력 오류 방지**: 스크립트 상단의 `_sys.reconfigure` 코드는 한글 윈도우즈 환경에서 출력 인코딩 문제(UnicodeEncodeError)를 방지하기 위한 것입니다. 절대 삭제하지 마세요!
*   **데이터의 정확성**: API에서 가져오는 데이터는 유튜브의 정책 및 업데이트에 따라 변경될 수 있으며, 실시간으로 정확하지 않을 수 있습니다.
