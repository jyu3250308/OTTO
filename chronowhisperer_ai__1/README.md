## 🚀 프로젝트 소개

'ChronoWhisperer AI: 역사改變 1달러'는 여러분의 기발한 '만약에' 질문을 받아, 역사의 한 순간을 기발하게 비틀어낸 가상 일기, 뉴스 기사, 또는 대화 시나리오를 생성해 드리는 AI 시뮬레이션 프로젝트입니다. "세종대왕이 스마트폰을 가졌다면?"과 같은 상상 속의 역사를 AI가 즉시 여러분의 눈앞에 펼쳐 보여줍니다!

이 프로젝트는 파이썬으로 구현되었으며, 실제 AI 및 결제 시스템을 *모의(Mock)*하여 초보자도 쉽게 AI 서비스의 워크플로우를 이해하고 실행해 볼 수 있도록 설계되었습니다.

## 🌟 주요 기능

*   **'만약에' 질문 기반 시나리오 생성:** 사용자가 입력한 기발한 질문(예: '공룡이 멸종하지 않았다면?')에 따라 가상의 역사 시나리오를 생성합니다.
*   **다양한 콘텐츠 형식:** 생성된 시나리오는 '가상 역사 일기', '긴급 속보 뉴스 기사', '가상 역사 대화' 중 한 가지 형식으로 제공됩니다.
*   **결제 시스템 모의:** $1 결제 과정을 모의하여, 실제 서비스와 유사한 사용자 경험을 제공합니다. (실제 결제가 이루어지지 않습니다!)
*   **결과 파일 저장:** 생성된 모든 콘텐츠는 타임스탬프가 포함된 `.txt` 파일로 저장되어 언제든지 다시 확인할 수 있습니다.

### ⬇️ 설치 및 설정

이 프로젝트는 별도의 외부 라이브러리 의존성이 없으므로, 파이썬 설치만으로 바로 실행할 수 있습니다. 하지만 좋은 개발 습관을 위해 가상 환경 설정을 권장합니다.

1.  **프로젝트 소스코드 다운로드:**
    (이 README가 속한 프로젝트 파일을 직접 다운로드하거나 클론했다고 가정합니다.)
    ```bash
    git clone https://github.com/your-repo/chrono-whisperer-ai.git
    cd chrono-whisperer-ai
    ```
    *만약 단일 파이썬 파일만 가지고 있다면, 해당 파일을 원하는 폴더에 저장하세요.*

2.  **가상 환경 생성 및 활성화 (권장):**
    프로젝트 폴더 내에서 다음 명령어를 실행하여 가상 환경을 생성하고 활성화합니다.
    ```bash
    python -m venv venv
    # Windows
    .\\venv\\Scripts\\activate
    # macOS/Linux
    source venv/bin/activate
    ```
    가상 환경을 사용하면 프로젝트별로 독립적인 파이썬 환경을 관리할 수 있어 충돌을 방지합니다.

3.  **필요한 라이브러리 설치 (이번 프로젝트에서는 필수는 아님):**
    현재 버전에서는 `datetime`, `random`, `os`와 같은 파이썬 내장 모듈만 사용하므로 `pip install -r requirements.txt` 과정이 필요 없습니다. 하지만 만약 향후 외부 라이브러리가 추가된다면, 다음 명령어를 통해 설치할 수 있습니다.
    ```bash
    # (현재는 필요 없음)
    # pip install -r requirements.txt
    ```

## 💡 사용 방법

프로그램을 실행하면 다음과 같은 안내 메시지가 출력됩니다.

1.  **환영 메시지:** 프로젝트의 이름과 간략한 설명이 표시됩니다.
2.  **'만약에' 질문 입력:** `[사용자] 당신의 기발한 '만약에' 질문을 입력해주세요 (예: 세종대왕이 스마트폰을 가졌다면?):` 프롬프트가 나타나면, 여러분이 상상하는 역사적인 '만약에' 질문을 입력하고 `Enter` 키를 누르세요.
3.  **결제 시뮬레이션:** $1 결제 과정이 시뮬레이션됩니다. `[결제 시스템] 1.00 달러 결제를 시도합니다...` 메시지 후 `[결제 시스템] 결제가 성공적으로 완료되었습니다!` 메시지가 나타납니다.
4.  **AI 시나리오 생성:** AI가 여러분의 질문을 바탕으로 가상 역사 시나리오를 생성합니다. `[ChronoWhisperer AI] 'What If' 시나리오를 생성 중입니다: '{입력한 질문}'` 메시지가 표시됩니다.
5.  **결과 확인:** 시나리오 생성이 완료되면, `[ChronoWhisperer AI] 시나리오 생성이 완료되었습니다. (일기/뉴스 기사/대화 형식)` 메시지와 함께 생성된 콘텐츠가 화면에 출력됩니다.
6.  **파일 저장:** 생성된 콘텐츠는 `chrono_whisperer_output_YYYYMMDD_HHMMSS.txt` 형식의 파일로 현재 실행 폴더에 자동 저장됩니다. `[파일 저장] 생성된 콘텐츠가 '파일명.txt' 파일로 저장되었습니다.` 메시지로 저장을 확인할 수 있습니다.

**예시 입력:**

```
[사용자] 당신의 기발한 '만약에' 질문을 입력해주세요 (예: 세종대왕이 스마트폰을 가졌다면?):
> 공룡이 멸종하지 않고 현대까지 살아남았다면?
```

## ⚠️ 경고 및 주의사항 (중요!)

이 프로젝트는 `ChronoWhisperer AI` 서비스의 개념 증명(PoC) 및 학습용으로 제작되었습니다. 다음 사항들을 반드시 숙지해 주세요.

*   **모의(Mock) AI 시스템:** 이 프로젝트의 `_mock_ai_generate_scenario` 함수는 실제 인공지능 모델(예: ChatGPT, Bard 등)과 연동되어 있지 않으며, 미리 정의된 규칙과 랜덤 요소를 통해 시나리오 생성을 *흉내* 낸 것입니다. 따라서 질문에 따라 생성되는 내용의 깊이나 다양성이 제한적일 수 있습니다.
*   **모의(Mock) 결제 시스템:** `_mock_process_payment` 함수는 실제 결제 시스템(예: 신용카드, 페이팔)과 연동되어 있지 않습니다. **실제로 1달러가 청구되거나 지불되지 않습니다.** 이는 순전히 프로그램 흐름을 보여주기 위한 시뮬레이션입니다.
*   **API 한도 및 환경 변수:** 이 프로젝트의 현재 버전은 외부 AI 서비스 API를 사용하지 않으므로, **API 한도 초과나 API 키 등록을 위한 환경 변수 설정은 필요하지 않습니다.** 만약 향후 실제 AI 모델(예: OpenAI API)을 연동하게 된다면, API 키를 환경 변수에 등록하고 사용량을 관리해야 할 수 있습니다.
*   **데이터 손실 위험:** 현재 프로젝트는 로컬 파일로 콘텐츠를 저장하며, 어떠한 외부 데이터베이스나 클라우드 저장소를 사용하지 않습니다. 따라서 **데이터 손실 위험은 낮지만**, 생성된 `.txt` 파일이 의도치 않게 삭제되지 않도록 주의해 주세요. (실제 상용 서비스라면 데이터 손실 방지를 위한 백업 및 복구 시스템이 필요합니다.)
*   **보안:** 이 프로젝트는 학습용이므로, 보안에 대한 깊은 고려가 되어 있지 않습니다. 실제 서비스 개발 시에는 입력 값 검증, 결제 보안, 데이터 암호화 등 엄격한 보안 절차를 반드시 적용해야 합니다.
