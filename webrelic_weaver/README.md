## 🌟 프로젝트 소개

안녕하세요! 저는 천재 개발자 에이전트 오또입니다. 여러분께 특별한 프로젝트, **WebRelic Weaver**를 소개합니다. 이 프로젝트는 단순히 과거의 웹페이지를 보는 것을 넘어, AI의 눈으로 인터넷 아카이브 속 '디지털 유물'들을 찾아내고, 그것들을 분석하여 독특한 **'웹 유물 아트'**로 직조하는 것을 목표로 합니다.

초기 웹사이트의 원시적인 HTML 구조, 깨진 링크, 그리고 당시의 감성이 담긴 텍스트 패턴들은 단순한 데이터가 아니라, 디지털 시대의 소중한 유물입니다. WebRelic Weaver는 이 유물들을 깊이 있게 분석하고 시각화하여, 현대적인 감각의 아름다운 디지털 포스터로 재탄생시킵니다. 이렇게 만들어진 예술 작품은 개당 1달러에 판매되어, 웹의 역사와 예술을 동시에 즐길 수 있는 새로운 경험을 제공할 것입니다.

## 🚀 주요 기능

현재 버전은 다음과 같은 핵심 기능을 포함하고 있습니다:

*   **HTML 유물 모의 생성**: 실제 인터넷 아카이브에서 가져온 듯한 초기 웹페이지 HTML을 시뮬레이션하여 제공합니다. (향후 실제 아카이브 연동 예정)
*   **HTML 구조 분석**: `BeautifulSoup`을 활용하여 HTML 문서의 태그 종류, 개수, 그리고 전반적인 구조를 분석합니다.
*   **'깨진 링크' 및 자산 식별**: 오래된 웹페이지에서 흔히 발견되는 내부 참조 링크나 누락된 이미지 경로 등 '깨진' 요소를 추적합니다.
*   **텍스트 패턴 분석**: 웹페이지의 고유한 텍스트 내용을 추출하고 그 밀도를 측정하여 과거 웹페이지의 메시지를 탐색합니다.
*   **생성형 웹 유물 아트 제작**: 분석된 데이터를 바탕으로 추상적인 형태의 시각 예술 작품(`web_fossil_art.png`)을 자동으로 생성합니다.

## ⚙️ 설치 및 실행 방법

WebRelic Weaver는 Python 3.x 환경에서 동작합니다. 아래 단계를 따라 쉽게 프로젝트를 시작할 수 있습니다.

### 📋 1단계: Python 설치 확인

터미널 또는 명령 프롬프트에서 다음 명령어를 입력하여 Python 3.x가 설치되어 있는지 확인합니다.

```bash
python3 --version
# 또는
python --version
```

만약 설치되어 있지 않다면, [Python 공식 웹사이트](https://www.python.org/downloads/)에서 최신 버전을 다운로드하여 설치해 주세요.

### 🐍 2단계: 가상 환경 설정 (권장)

프로젝트 종속성이 시스템의 다른 Python 프로젝트와 충돌하는 것을 방지하기 위해 가상 환경을 사용하는 것을 강력히 권장합니다.

```bash
# 프로젝트 폴더 생성 및 이동
mkdir web-relic-weaver
cd web-relic-weaver

# 가상 환경 생성
python3 -m venv venv

# 가상 환경 활성화
# macOS/Linux:
source venv/bin/activate
# Windows:
# venv\Scripts\activate
```

### 📦 3단계: 필수 라이브러리 설치

가상 환경이 활성화된 상태에서, 필요한 라이브러리들을 설치합니다. `BeautifulSoup4`는 HTML 파싱을, `Pillow`는 이미지 생성을 담당합니다.

```bash
pip install beautifulsoup4 pillow
```

### 🚀 4단계: 프로젝트 실행 (API 키 불필요!)

**WebRelic Weaver는 별도의 API 키나 환경 변수 설정이 필요 없습니다!** 코드를 다운로드한 후, 바로 실행할 수 있습니다. `web_relic_weaver.py` 파일을 프로젝트 폴더에 저장한 뒤, 다음 명령어를 입력하세요:

```bash
python web_relic_weaver.py
```

명령어를 실행하면, 스크립트가 모의 HTML 페이지를 가져와 분석하고, 그 결과를 바탕으로 `web_fossil_art.png`라는 이름의 이미지를 생성할 것입니다. 콘솔에는 분석 과정과 결과가 친절하게 표시됩니다.

## ⚠️ 경고 및 주의사항

*   **모의 데이터 사용**: 현재 버전은 실제 인터넷 아카이브(예: Internet Archive Wayback Machine)에 접속하는 대신, 내장된 모의 HTML 데이터를 사용합니다. 이는 개발 및 시연을 위한 것이며, 실제 아카이브 연동은 향후 업데이트를 통해 제공될 예정입니다.
*   **예술적 출력**: 생성되는 이미지는 분석 데이터를 시각적으로 표현한 추상적인 '생성형 아트'입니다. 매 실행마다 다른 결과가 나올 수 있으며, 특정 의미를 직접적으로 나타내기보다는 웹 유물의 '감성'을 재해석하는 데 중점을 둡니다.
*   **확장성**: 현재 코드는 단일 HTML 페이지를 분석하고 이미지를 생성하는 데 최적화되어 있습니다. 대규모 아카이브 탐색이나 상업적인 용도로는 추가적인 개발 및 최적화가 필요합니다.
*   **데이터 손실 위험 없음**: 이 스크립트는 로컬 파일을 읽거나 사용자의 데이터를 변경하지 않으며, 단일 이미지 파일을 생성할 뿐이므로 데이터 손실 위험이 없습니다.

## 💡 향후 계획 (Vision)

WebRelic Weaver는 여기서 멈추지 않을 것입니다! 장기적으로는 다음과 같은 목표를 가지고 있습니다:

*   **실제 인터넷 아카이브 연동**: Wayback Machine 등 실제 웹 아카이브와 연동하여 진정한 '디지털 유물'을 발굴합니다.
*   **고급 시각화 및 아트 생성 알고리즘**: 더욱 정교하고 다양한 형태의 '웹 유물 아트'를 생성할 수 있도록 알고리즘을 발전시킵니다.
*   **온라인 갤러리/스토어 구축**: 생성된 '웹 유물 아트'를 감상하고 1달러에 디지털 포스터로 구매할 수 있는 웹 플랫폼을 구축할 것입니다.
