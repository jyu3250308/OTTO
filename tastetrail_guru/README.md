# 🍲 TasteTrail Guru (맛길 도사) 🧑‍🍳

요리 초보자들을 위한 AI 미식 가이드, '맛길 도사'에 오신 것을 환영합니다! 🥳 이 프로젝트는 인공지능이 요리 초보자들이 겪는 어려움을 해소하고, 미식의 세계로 첫발을 내딛는 데 필요한 핵심 지식들을 쉽고 재미있게 가르쳐 드립니다. 퀴즈를 통해 요리 상식을 배우고, AI가 당신의 학습 패턴을 분석하여 맞춤형 학습 경로와 효과적인 광고 문구까지 제안해 드립니다.

## ✨ 프로젝트 개요

'TasteTrail Guru'는 요리 초보자들이 가장 어려워하는 식재료 특징, 요리 용어, 필수 조리법 원리 등을 퀴즈 형식으로 제공하며, 틀린 문제에 대한 상세한 해설을 통해 학습을 돕습니다. AI는 사용자의 퀴즈 결과(특히 자주 틀리는 상식)를 분석하여 개인화된 학습 가이드를 제공하고, 이를 바탕으로 특정 식재료나 조리 도구에 대한 광고 문구를 생성하여 수익 모델을 시뮬레이션합니다.

## 🚀 주요 기능

*   **인터랙티브 요리 퀴즈**: 주요 식재료, 용어, 조리 원리에 대한 개념 퀴즈를 풀어보세요.
*   **상세 해설 제공**: 오답 시 정확한 정답과 친절한 설명을 통해 학습 효과를 극대화합니다.
*   **사용자 학습 통계 추적**: 퀴즈 진행 상황과 정/오답 기록을 저장하여 학습 패턴을 파악합니다.
*   **개인 맞춤형 학습 경로 제안**: 사용자가 자주 틀리는 카테고리를 분석하여 보강이 필요한 분야를 알려줍니다.
*   **모의 광고 문구 생성**: 학습 패턴 분석을 통해 특정 제품에 대한 효과적인 광고 문구를 (개념적으로) 생성합니다.

## 🛠️ 시작하기

이 프로젝트를 실행하기 위해 필요한 준비물과 단계를 안내해 드립니다.

### 📋 전제 조건

*   **Python 3.8 이상**: 이 프로젝트는 Python으로 작성되었습니다.

### 📦 설치 및 실행 방법

이 프로젝트는 단일 파이썬 파일로 구성되어 있으며, 별도의 라이브러리 설치 없이 파이썬 기본 환경에서 실행할 수 있습니다. 💡 **API 키 불필요!** 이 프로젝트는 별도의 API 키나 환경 변수 설정 없이 바로 실행할 수 있습니다. `.env` 파일을 만들 필요가 전혀 없습니다!

1.  **소스코드 다운로드**: `tastetrail_guru.py` 파일을 컴퓨터의 원하는 위치에 다운로드합니다.

    ```bash
    # 예시: (git clone이 아닌 직접 다운로드 후 진행해주세요)
    # cd /path/to/your/project/directory
    ```

2.  **가상 환경 설정 (권장)**:
    프로젝트마다 독립적인 파이썬 환경을 구축하는 것은 좋은 습관입니다. 다음 명령어를 사용하여 가상 환경을 생성하고 활성화하세요.

    *   **가상 환경 생성**: `venv`라는 이름으로 가상 환경을 생성합니다.
        ```bash
        python -m venv venv
        ```

    *   **가상 환경 활성화**:
        *   **macOS / Linux**: (macOS나 Linux 사용자)
            ```bash
            source venv/bin/activate
            ```
        *   **Windows**: (Windows 사용자)
            ```bash
            venv\Scripts\activate
            ```

3.  **프로젝트 실행**: 가상 환경이 활성화된 상태에서 다음 명령어를 사용하여 'TasteTrail Guru'를 실행합니다.

    ```bash
    python tastetrail_guru.py
    ```

    명령어를 입력하면 퀴즈가 시작되고, 질문에 답변하며 상호작용할 수 있습니다.

## 🧑‍💻 사용 방법

1.  `python tastetrail_guru.py` 명령어를 실행하면, 즉시 요리 퀴즈가 시작됩니다.
2.  질문을 읽고 당신의 답변을 입력창에 정확한 문장으로 입력해주세요.
3.  정답 여부와 함께 상세한 해설이 제공됩니다.
4.  퀴즈가 종료되면, AI가 당신의 학습 데이터를 분석하여 맞춤형 학습 경로를 제안하고, 가상의 광고 문구를 생성합니다.
5.  생성된 학습 가이드는 `personalized_learning_path.txt` 파일로, 광고 문구는 `generated_ad_copy.txt` 파일로 프로젝트 폴더에 저장됩니다.
6.  당신의 퀴즈 진행 상황은 `user_progress.json` 파일에 자동으로 저장되므로, 다음에 다시 실행해도 이어서 학습할 수 있습니다.

## ⚠️ 중요 사항 및 주의사항

*   **Windows 한글 출력 문제 방지**: `tastetrail_guru.py` 파일 상단에 있는 다음 코드는 Windows 환경에서 한글 출력이 깨지거나 `UnicodeEncodeError`가 발생하는 것을 방지하기 위한 것입니다. **절대 삭제하지 마세요!**
    ```python
    import sys as _sys
    for _s in (_sys.stdout, _sys.stderr):
        try:
            _s.reconfigure(encoding="utf-8", errors="replace")
        except Exception:
            pass
    ```
*   **데이터 저장**: 퀴즈 진행 상황은 `user_progress.json` 파일에 저장됩니다. 이 파일을 삭제하면 모든 학습 기록이 초기화됩니다.
*   **출력 파일**: `personalized_learning_path.txt`와 `generated_ad_copy.txt` 파일은 스크립트 실행 시 항상 새로 생성되거나 덮어쓰여집니다.
*   **모의 데이터**: 현재 퀴즈 데이터는 3가지 질문으로 제한된 모의 데이터입니다. 실제 서비스에서는 훨씬 더 방대한 데이터가 필요합니다.
*   **광고 문구 생성**: 광고 문구 생성 기능은 개념 증명(Proof of Concept)을 위한 매우 단순화된 로직으로 구현되었습니다. 실제 AI 기반 광고 문구 생성은 훨씬 더 복잡한 모델을 요구합니다.
*   **컨셉 증명**: 이 프로젝트는 'TasteTrail Guru'의 컨셉과 가능성을 보여주기 위한 초기 단계의 코드입니다. 실제 상용 서비스로 발전시키기 위해서는 추가적인 개발과 기능 확장이 필요합니다.
