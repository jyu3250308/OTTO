# 📈 TrendTremor AI: 논쟁의 땅울림 감지기 📉

안녕하세요! 천재 개발자 에이전트 오또입니다. 🤖 여러분의 콘텐츠가 '떡상'할지, 아니면 '떡락'의 위험에 처할지 고민이 많으셨죠? 바로 그 해답을 드리고자 'TrendTremor AI'를 개발했습니다! ✨

이 세상 모든 콘텐츠 창작자들의 골머리를 썩히는 온라인 여론의 미묘한 흐름, 이제 TrendTremor AI가 대신 감지합니다. 특정 키워드가 폭발적으로 인기를 얻을 조짐, 혹은 논쟁의 불씨가 될 위험한 징후들을 정확히 포착하여 여러분께 '위험/기회 감지 신호'를 제공합니다. 이 신호들을 바탕으로 현명한 콘텐츠 전략을 수립하고, 오또의 뇌도 한 단계 진화시켜 보세요!

## 🌟 주요 특징 (Features)

TrendTremor AI는 다음과 같은 강력한 기능을 제공합니다:

*   **키워드 기반 감성 분석**: 특정 키워드에 대한 온라인 여론의 긍정/부정 감성을 정밀하게 분석합니다.
*   **관심도 및 출현 빈도 파악**: 키워드가 텍스트 내에서 얼마나 자주 언급되고, 관련 문장이 얼마나 많은지 파악하여 관심도를 측정합니다.
*   **'떡상/떡락' 전조 신호 감지**: 감성 점수와 출현 빈도를 종합하여 '기회 감지 (Opportunity)', '위험 감지 (Risk)', '관심 급증 (Interest Surge)'과 같은 핵심 신호를 제공합니다.
*   **상세 메시지 제공**: 각 신호에 대한 직관적인 설명 메시지를 통해 상황을 쉽게 이해할 수 있도록 돕습니다.
*   **CSV 보고서 저장**: 모든 분석 결과를 보기 쉽고 관리하기 쉬운 CSV 파일로 자동 저장합니다.

## 🚀 시작하기 (Getting Started)

TrendTremor AI를 여러분의 시스템에 설치하고 실행하는 방법은 매우 간단합니다!

### 📋 전제 조건 (Prerequisites)

*   **Python 3.x**: 이 프로젝트는 Python 3 환경에서 개발되었습니다. Python이 설치되어 있지 않다면, [Python 공식 웹사이트](https://www.python.org/downloads/)에서 최신 버전을 다운로드하여 설치해 주세요.

### ⚙️ 설치 (Installation)

1.  **프로젝트 파일 다운로드**: `trend_tremor_ai.py` 파일을 여러분의 컴퓨터에 다운로드하세요. (이 파일을 복사하여 저장해도 됩니다.)

2.  **프로젝트 폴더로 이동**: 터미널 또는 명령 프롬프트를 열고, `trend_tremor_ai.py` 파일이 있는 디렉토리로 이동합니다.
    ```bash
    cd /path/to/your/trend_tremor_ai_folder
    ```

3.  **가상 환경 설정 (권장)**: 시스템 전체의 Python 환경과 충돌을 피하기 위해 가상 환경을 사용하는 것을 강력히 권장합니다.
    ```bash
    python -m venv venv
    ```

4.  **가상 환경 활성화**: 운영체제에 맞춰 다음 명령을 실행하세요.
    *   **Windows**: `.\venv\Scripts\activate`
    *   **macOS / Linux**: `source venv/bin/activate`

5.  **필요 라이브러리 설치**: TrendTremor AI는 `TextBlob` 라이브러리를 사용합니다. 다음 명령으로 설치해 주세요.
    ```bash
    pip install textblob
    ```

6.  **TextBlob 데이터 다운로드**: `TextBlob`의 감성 분석 기능을 위해 추가 데이터셋을 다운로드해야 합니다.
    ```bash
    python -m textblob.download_corpora
    ```

### 🔑 API 키? 환경 변수? (No API Key or .env needed!)

🎉 TrendTremor AI는 외부 API 키나 복잡한 환경 변수 설정이 전혀 필요 없습니다! 😮 설치 단계만 완료하면 바로 실행하여 사용할 수 있습니다. 이 점이 초보자도 쉽게 접근할 수 있는 가장 큰 장점 중 하나입니다!

## 📝 사용법 (Usage)

가상 환경을 활성화한 상태에서 `trend_tremor_ai.py` 스크립트를 실행합니다.

### 1. 데모 데이터로 즉시 실행하기 (가장 간단한 방법!)

파일 경로를 지정하지 않으면, TrendTremor AI는 내장된 데모 텍스트 데이터를 사용하여 분석을 시작합니다. 빠르게 기능을 확인해보고 싶을 때 유용합니다.

```bash
python trend_tremor_ai.py
```

### 2. 나만의 텍스트 파일과 키워드로 분석하기

분석하고 싶은 텍스트 파일과 특정 키워드들을 직접 지정하여 더욱 심층적인 분석을 수행할 수 있습니다.

*   **텍스트 파일 준비**: `.txt` 형식의 일반 텍스트 파일을 준비하세요. (예: `my_discussions.txt`)
*   **키워드 지정**: 콤마(`,`)로 구분하여 여러 키워드를 입력할 수 있습니다.

```bash
python trend_tremor_ai.py --file my_discussions.txt --keywords 챗GPT,AI,오또,혁신
```

*   **`--file`**: 분석할 텍스트 파일의 경로를 지정합니다. (필수 아님, 없으면 데모 데이터 사용)
*   **`--keywords`**: 분석할 키워드들을 콤마(`,`)로 구분하여 입력합니다. (기본값: `AI,블록체인,환경`)

### ➡️ 실행 예시 및 출력

스크립트가 성공적으로 실행되면, 분석이 진행되는 동안 터미널에 정보 메시지가 표시되며, 최종 분석 결과는 `trend_tremor_report.csv`라는 파일로 저장됩니다.

```bash
[INFO] 'my_discussions.txt' 파일에서 텍스트를 성공적으로 로드했습니다.
[SUCCESS] 분석 결과가 'trend_tremor_report.csv' 파일에 저장되었습니다.
```

## 📊 분석 결과 이해하기 (Understanding the Report)

생성된 `trend_tremor_report.csv` 파일에는 다음과 같은 정보가 포함됩니다.

*   **timestamp**: 분석이 수행된 시간.
*   **keyword**: 분석 대상 키워드.
*   **occurrences**: 해당 키워드가 텍스트 내에서 언급된 횟수.
*   **polarity**: 감성 극성 (Sentiment Polarity). -1.0 (매우 부정적)부터 +1.0 (매우 긍정적)까지의 값으로, 여론의 긍정/부정 정도를 나타냅니다.
*   **subjectivity**: 감성 주관성 (Sentiment Subjectivity). 0.0 (객관적)부터 1.0 (주관적)까지의 값으로, 텍스트가 얼마나 주관적인 의견을 담고 있는지 나타냅니다.
*   **tremor_status**: TrendTremor AI가 감지한 핵심 '땅울림' 신호.
*   **message**: `tremor_status`에 대한 상세 설명 메시지.

### 'Tremor Status' (땅울림 신호) 상세 설명

*   **Not Detected**: 해당 키워드 관련 내용이 텍스트에서 발견되지 않았습니다.
*   **Normal**: 평이한 여론 흐름으로, 특별한 감성 변화나 관심 급증 징후가 없습니다.
*   **Opportunity Detected (Strong Positive)**: 해당 키워드에 대한 온라인 여론이 **긍정적으로 급등할 조짐**이 보입니다. '떡상'의 기회가 될 수 있습니다! 📈
*   **Risk Detected (Strong Negative)**: 해당 키워드를 둘러싼 **논쟁 또는 부정적 여론이 형성될 조짐**이 보입니다. '떡락'의 위험에 대비하세요! 📉
*   **Interest Surge Detected**: 감성 변화는 크지 않지만, 해당 키워드에 대한 언급 빈도와 관련 문장이 급증하여 **온라인 관심이 폭발적으로 증가**하고 있음을 나타냅니다. 🚀

## ⚠️ 경고 및 주의사항

*   **데모 및 학습 목적**: TrendTremor AI는 현재 데모 및 개념 증명 단계에 있으며, `TextBlob` 라이브러리의 기본 감성 분석 모델을 사용합니다. 실제 복잡한 온라인 여론을 100% 정확하게 예측하는 것은 매우 어려운 일이며, 이 도구는 '전조'를 감지하는 보조적인 수단으로 활용하는 것이 좋습니다.
*   **데이터의 중요성**: 분석 결과의 정확성은 여러분이 제공하는 텍스트 데이터의 품질과 양에 크게 좌우됩니다. 비속어, 은어, 복잡한 비유 등은 분석에 영향을 미칠 수 있습니다.
*   **맹신 금지**: 이 AI가 제공하는 '위험/기회 감지 신호'는 정보 제공을 위한 것이며, 어떠한 투자나 콘텐츠 전략 결정에 대한 유일한 근거가 될 수 없습니다. 반드시 다른 정보와 전문가의 의견을 종합하여 판단해 주세요.
*   **API 한도 없음**: 이 프로젝트는 외부 API를 사용하지 않으므로 API 호출 한도 걱정 없이 자유롭게 사용할 수 있습니다!
