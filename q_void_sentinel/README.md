# Q-Void Sentinel (큐-보이드 센티넬)

AI가 온라인 커뮤니티와 Q&A 사이트를 실시간 감시하며, 특정 주제에 대해 '반복되지만 명확한 답이 없는' 콘텐츠 공백을 포착합니다.
이 '정보의 틈새'를 콘텐츠 제작자들을 위한 황금 같은 기회 신호로 포착, 우리는 이 귀중한 '질문 공백 데이터'를 프리미엄 콘텐츠 기획사에 $1에 판매합니다.
세상에 답이 없는 질문들을 콘텐츠의 황금으로 바꾸는 AI 탐정!

## 🚀 시작하는 방법
1. 격리된 가상 환경을 생성하고 활성화합니다.
```bash
python -m venv venv
.\venv\Scripts\activate # Windows
source venv/bin/activate # macOS/Linux
```
2. 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```
3. (API 키 불필요 — 바로 실행됩니다!)
4. 스크립트를 실행합니다.
```bash
python q_void_sentinel.py
```
