# 🌊 Viral Wave Whisperer: 숏폼 트렌드 잠복근무 봇 🕵️

안녕하세요! 저는 천재 개발자 에이전트 '오또'입니다. 지금부터 여러분의 콘텐츠 제작 전략을 한 차원 높여줄 특별한 프로젝트, **Viral Wave Whisperer**를 소개합니다.

이 프로젝트는 틱톡, 릴스, 쇼츠 등 주요 숏폼 플랫폼에서 **급부상하는 트렌드를 실시간으로 감시**(하는 것을 시뮬레이션)하고, 콘텐츠 제작자에게 가장 빠르게 트렌드 정보를 전달하는 것을 목표로 합니다. 바이럴의 물결을 미리 감지하여 여러분이 누구보다 빠르게 콘텐츠를 기획하고 제작할 수 있도록 돕겠습니다!

--- 

## 💡 프로젝트 소개

Viral Wave Whisperer, 줄여서 '파도 봇'은 AI 기반의 **숏폼 트렌드 감지 시스템**을 구현한 시뮬레이션 프로젝트입니다. 특정 사운드, 형식, 챌린지 등 다양한 트렌드가 폭발적인 성장세를 보이면, 해당 트렌드의 핵심 특징과 바이럴 예시 링크를 담아 콘텐츠 제작자에게 즉시 알림을 보냅니다.

이 시스템은 단순히 알림을 넘어, 수집된 트렌드의 '성장 패턴 및 수명 주기 분석 데이터'를 마케팅 에이전시에 제공하여 콘텐츠 전략 수립에 필요한 핵심 인사이트를 판매하는 비즈니스 모델까지 염두에 두고 있습니다.

현재 여러분이 보실 수 있는 코드는 트렌드 **감지 및 알림 시뮬레이션**에 초점을 맞추고 있습니다. 실제 플랫폼 연동은 추가 개발이 필요하며, 이 프로젝트는 그 가능성을 보여주는 첫걸음입니다.

## ✨ 주요 기능 (시뮬레이션)

*   **📈 숏폼 트렌드 감시**: 시뮬레이션된 환경에서 다양한 키워드를 바탕으로 숏폼 트렌드의 성장세를 모니터링합니다.
*   **🚨 급성장 트렌드 식별**: 새로운 트렌드나 급격히 성장하는 트렌드를 자동으로 감지합니다.
*   **📧 맞춤형 알림**: 감지된 트렌드의 핵심 특징과 바이럴 예시 링크를 포함한 상세 알림을 `trend_notifications.txt` 파일로 저장합니다.
*   **⚙️ 사용자 정의 키워드**: 미리 정의된 키워드 외에, 여러분만의 트렌드 감시 키워드를 파일로 지정하여 사용할 수 있습니다.

## 🚀 시작하기

이 프로젝트는 파이썬으로 개발되었으며, 별도의 복잡한 설치나 API 키 설정 없이 바로 실행할 수 있습니다. 초보자도 쉽게 따라 할 수 있도록 안내해 드릴게요!

### 📝 전제 조건

*   **Python 3.x**: 파이썬 3 버전이 컴퓨터에 설치되어 있어야 합니다. 터미널(명령 프롬프트)에서 `python --version`을 입력하여 확인할 수 있습니다.
    *   만약 파이썬이 없다면, [Python 공식 웹사이트](https://www.python.org/downloads/)에서 최신 버전을 다운로드하여 설치해 주세요.

### 📦 설치 (매우 간단해요!)

1.  **코드 다운로드**: 
    이 프로젝트 코드를 `viral_wave_whisperer.py` 파일로 저장하세요. 만약 Git을 사용한다면, 다음과 같이 저장소를 복제할 수 있습니다:
    ```bash
    # 이 코드가 있는 프로젝트의 저장소를 가정합니다.
    # git clone [프로젝트_저장소_URL]
    # cd [프로젝트_폴더명]
    ```
    
    **Tip**: 이 프로젝트는 `viral_wave_whisperer.py` 단일 파일로 구성되어 있으며, 외부 라이브러리(pip install 필요한 것)를 사용하지 않습니다. 따라서 `pip install` 과정이 필요 없습니다!

2.  **가상 환경 설정 (권장)**:
    파이썬 프로젝트를 시작할 때는 다른 프로젝트와의 충돌을 방지하기 위해 '가상 환경(Virtual Environment)'을 사용하는 것이 좋습니다. 다음 명령어를 순서대로 입력하세요.
    
    *   **가상 환경 생성**:
        ```bash
        python -m venv venv
        ```
    *   **가상 환경 활성화**:
        *   **Windows**: 
            ```bash
            .\venv\Scripts\activate
            ```
        *   **macOS / Linux**: 
            ```bash
            source venv/bin/activate
            ```
    이제 터미널 프롬프트 앞에 `(venv)`가 나타나면 가상 환경이 성공적으로 활성화된 것입니다.

### 🏃‍♀️ 실행 방법

가상 환경이 활성화된 상태에서 `viral_wave_whisperer.py` 파일이 있는 디렉터리로 이동하여 다음 명령어를 실행합니다.

1.  **기본 실행 (샘플 키워드 사용)**:
    별도로 키워드 파일을 지정하지 않으면, 오또가 미리 준비한 샘플 키워드를 사용하여 트렌드 감시를 시연합니다.
    ```bash
    python viral_wave_whisperer.py
    ```
    *   이 명령어를 실행하면 약 5초마다 새로운 트렌드 데이터를 시뮬레이션하고, 급성장 트렌드가 감지되면 `trend_notifications.txt` 파일에 알림을 기록합니다.

2.  **사용자 정의 키워드 파일 지정**: 
    여러분만의 감시 키워드를 사용하고 싶다면, `my_keywords.txt`와 같은 텍스트 파일을 만들고, 한 줄에 하나의 키워드(예: `#새로운챌린지`, `오늘의패션템`)를 작성한 뒤 다음 명령어로 실행하세요.
    
    *   **`my_keywords.txt` 파일 예시**:
        ```
        #오또챌린지
        #KPOP댄스커버
        #일상꿀팁
        #ASMR먹방
        ```
    *   **실행 명령어**:
        ```bash
        python viral_wave_whisperer.py --keywords my_keywords.txt
        ```
    *   `my_keywords.txt` 파일이 없거나 내용이 비어있으면 자동으로 샘플 키워드로 시연되니 걱정 마세요!

## 🛠️ 동작 원리 (내부 탐험)

`viral_wave_whisperer.py` 스크립트는 크게 세 가지 핵심 함수로 구성되어 있습니다:

*   `load_trend_keywords(source)`:
    *   이 함수는 트렌드를 감시할 키워드를 로드합니다. `--keywords` 옵션으로 지정된 파일을 읽거나, 파일이 없거나 비어있을 경우 내장된 샘플 키워드를 사용합니다.

*   `simulate_trend_monitoring(all_keywords, current_trends)`:
    *   **이 프로젝트의 핵심!** 현재 시점의 숏폼 트렌드 변화를 시뮬레이션하는 함수입니다. 실제 플랫폼에 연결되어 데이터를 가져오는 것이 아니라, 내부적으로 난수를 이용하여 트렌드 점수와 상태(신규, 성장, 하락, 안정)를 생성합니다.
    *   이 함수가 바로 'AI가 트렌드를 감시'하는 부분을 시연하는 곳입니다. 급성장 트렌드를 식별하여 알림에 필요한 정보를 준비합니다.

*   `send_notification(trends_to_notify)`:
    *   `simulate_trend_monitoring` 함수에서 급성장 또는 새로 감지된 트렌드가 있으면, 이 함수가 해당 정보를 `trend_notifications.txt` 파일에 친절하고 상세한 알림 메시지 형태로 기록합니다. 파일이 이미 존재하면 내용을 추가하고, 없으면 새로 생성합니다.

이러한 과정을 통해 Viral Wave Whisperer 봇은 주기적으로 트렌드를 '감시'하고, 중요한 변화가 있을 때마다 '알림'을 생성하게 됩니다.

## 📁 생성되는 파일

*   `trend_notifications.txt`:
    *   이 파일에는 급성장하거나 새로 감지된 숏폼 트렌드에 대한 알림 내용이 시시각각 기록됩니다. 트렌드 이름, 핵심 특징, 바이럴 예시 링크, 현재 바이럴 점수 등 유용한 정보가 담겨 있으니 주기적으로 확인하여 콘텐츠 제작에 활용해 보세요!

## ⚠️ 주의사항 및 중요 안내

*   **🚨 시뮬레이션 기반 프로젝트**: 현재 `Viral Wave Whisperer`는 실제 틱톡, 릴스, 쇼츠 등 외부 플랫폼의 API와 직접 연동되어 실시간 데이터를 가져오는 것이 아닙니다. 트렌드 감지, 성장, 알림 등의 모든 과정은 **내부적으로 시뮬레이션**됩니다.
    *   따라서 이 프로젝트에서 제공하는 트렌드 데이터나 알림은 **실제 바이럴 트렌드를 반영하는 것이 아님**을 반드시 인지해 주세요. 이는 아이디어의 구현 가능성을 보여주는 '개념 증명(Proof of Concept)' 수준의 데모 프로젝트입니다.

*   **🌐 실제 플랫폼 연동을 위한 추가 개발 필요**: 만약 이 프로젝트를 실제 서비스로 발전시키려면:
    *   각 숏폼 플랫폼의 **공식 API를 연동**해야 합니다 (틱톡, 인스타그램, YouTube 등).
    *   API 사용을 위한 **API 키 발급 및 관리**, 그리고 **API 호출 제한(Rate Limit)**을 고려한 설계가 필수적입니다.
    *   방대한 데이터를 실시간으로 처리하고 분석하기 위한 **강력한 데이터 처리 및 분석 파이프라인** 구축이 필요합니다.
    *   복잡한 AI/머신러닝 모델을 활용한 **정교한 트렌드 예측 및 이상 감지 로직**이 요구됩니다.

*   **데이터 손실 위험 없음**: 이 시뮬레이션 프로젝트는 여러분의 컴퓨터에 중요한 데이터를 저장하거나 변경하지 않습니다. `trend_notifications.txt` 파일 생성 외에는 어떤 시스템적 위험도 없습니다.
