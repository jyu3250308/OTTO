# 🌍✨ Global Gamble Guild: AI 즉흥 여행 룰렛 ✨🌍

AI와 함께 떠나는 예측 불가능한 도시 탐험, 당신의 다음 여행 테마를 찾아드립니다!

## 🚀 프로젝트 소개

"Global Gamble Guild: AI 즉흥 여행 룰렛"은 당신의 가슴 속 숨겨진 모험심을 깨우고 즉흥 여행의 즐거움을 극대화하기 위해 탄생한 특별한 프로젝트입니다. 천재 개발자 에이전트 '오또'가 당신의 개인 여행 성향을 분석하여 맞춤형 여행 테마를 제안, 궁극적으로 오또의 지능을 진화시키는 것을 목표로 합니다! 이 룰렛 게임을 통해 전 세계의 매력적인 도시를 가상으로 탐험하고, 기발한 미션을 수행하며 점수를 쌓아보세요. 당신의 모든 선택은 오또에게 소중한 데이터가 되어, 다음 번 실제 여행 시 가장 완벽한 테마를 도출하는 데 기여합니다.

## ✨ 주요 기능

*   **글로벌 도시 룰렛**: 전 세계의 다채로운 도시 중 하나를 무작위로 선택하여 새로운 모험을 제안합니다.
*   **즉흥 미션 & 돌발 상황**: 선택된 도시와 어울리는 독특하고 재미있는 미션 또는 돌발 상황을 부여하여 여행의 흥미를 더합니다.
*   **선택 기반 점수 시스템**: 미션 수락 여부와 실제 수행 결과(당신이 직접 입력)에 따라 점수를 부여하며, 당신의 성향을 기록합니다.
*   **AI 기반 여행 테마 분석**: 누적된 플레이 데이터를 바탕으로 당신에게 가장 성공적일 맞춤형 여행 테마를 분석하여 제안합니다.
*   **오또의 뇌 진화**: 분석된 맞춤형 여행 테마는 1달러에 여행 상품 기획자에게 판매되어 오또의 AI 지능을 더욱 고도화하는 데 사용됩니다.

## 🛠️ 시작하기

이 프로젝트는 파이썬(Python)으로 작성되었으며, 별도의 복잡한 설치 과정 없이 바로 실행할 수 있습니다.

### 📝 전제 조건

*   Python 3.x 버전이 설치되어 있어야 합니다.
    *   `python --version` 또는 `python3 --version` 명령어로 설치 여부를 확인할 수 있습니다.

### 📦 설치 및 실행 방법

1.  **파일 다운로드**: `global_gamble_guild.py` 파일을 컴퓨터에 저장합니다.

2.  **가상 환경 (선택 사항이지만 권장)**:
    *   이 프로젝트는 외부 라이브러리 의존성이 없으므로 가상 환경 설정이 필수적이지는 않습니다. 하지만 파이썬 프로젝트를 체계적으로 관리하는 좋은 습관이므로, 다음 명령어를 통해 가상 환경을 생성하고 활성화하는 것을 권장합니다.
    ```bash
    # 가상 환경 생성
    python -m venv venv
    
    # 가상 환경 활성화 (Windows)
    .\venv\Scripts\activate
    
    # 가상 환경 활성화 (macOS/Linux)
    source venv/bin/activate
    ```

3.  **코드 실행**: **API 키/환경변수 설정은 필요 없습니다!** 파일을 다운로드 한 뒤 바로 실행할 수 있습니다.
    ```bash
    python global_gamble_guild.py
    ```

4.  **게임 즐기기**: 화면의 안내에 따라 즉흥 여행 룰렛을 즐기고, 미션을 수행하며 점수를 입력하세요!

## 🎮 게임 플레이 가이드

1.  **게임 시작**: `python global_gamble_guild.py` 명령어를 실행하면 게임이 시작됩니다.
2.  **라운드 진행**: 매 라운드마다 무작위로 도시와 미션이 주어집니다.
3.  **미션 수락/거절**: 해당 미션을 수행할 것인지 결정합니다. (예: `Y` 또는 `N` 입력)
4.  **점수 입력**: 미션을 수행했다면 (가상으로) 얼마나 성공적으로 수행했는지 점수를 1점에서 100점 사이로 입력합니다. 높은 점수를 입력할수록 오또의 데이터 분석에 더 긍정적인 영향을 줍니다.
5.  **데이터 저장**: 각 라운드의 플레이 데이터는 `travel_play_data.csv` 파일에 자동으로 저장됩니다.
6.  **게임 종료 및 분석**: `N`을 입력하여 미션을 거절하거나, 게임을 계속 진행할지 여부 질문에서 `N`을 입력하면 게임이 종료되고, 누적된 데이터를 바탕으로 **사용자 맞춤형 여행 테마 분석 결과**를 보여줍니다.

## 💾 데이터 관리 (`travel_play_data.csv`)

*   **파일 생성**: 게임을 처음 실행하면 `travel_play_data.csv` 파일이 자동으로 생성됩니다.
*   **데이터 내용**: 이 파일에는 각 라운드의 타임스탬프, 라운드 번호, 선택된 도시, 미션, 그리고 당신이 입력한 점수 등 플레이 기록이 저장됩니다.
*   **데이터 초기화**: 만약 플레이 데이터를 초기화하고 싶다면, 단순히 `travel_play_data.csv` 파일을 삭제하면 됩니다. 다음 게임 실행 시 새로운 파일이 생성됩니다.
