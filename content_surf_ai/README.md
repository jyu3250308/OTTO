# Content Surf AI: 트렌드 파도 감시병

AI가 유튜브, 블로그 등 콘텐츠 플랫폼을 실시간 서핑하며 '뜨는 파도(새로운 트렌드)'와 '밀물(과포화된 주제)'을 감지합니다.
콘텐츠 크리에이터에게 기회 포착과 레드오션 회피 시점을 정확히 알려주는 인공지능 서핑 보드이자 감시병!
이 인사이트를 익명으로 수집, 트렌드 예측 모델을 고도화하여 1달러를 법니다.

## 🚀 시작하는 방법
1. 격리된 가상 환경을 생성하고 활성화합니다.
```bash
python -m venv venv
.\venv\Scripts\activate # Windows
source venv/bin/activate # macOS/Linux
```
2. 필요한 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```
3. (API 키 불필요 — 바로 실행됩니다!)
4. 스크립트를 실행합니다.
```bash
python content_surf_ai.py
```
