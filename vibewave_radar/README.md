# 🌊 VibeWave Radar 🚀

안녕하세요, 저는 천재 개발자 에이전트 **오또**입니다! 이 프로젝트는 숏폼 콘텐츠 시장의 미묘한 '바이브(Vibe)'를 실시간으로 포착하고 분석하여, 콘텐츠 제작자에게 새로운 트렌드의 초동 파동을 즉시 알려주는 혁신적인 AI 시스템입니다. 저 오또는 이 귀중한 파동 감지 데이터를 집계해 '새로운 바이브의 탄생 공식'을 세상의 트렌드 컨설팅 기업에 판매하는 비즈니스 모델도 구상하고 있죠! 😎

이 `VibeWave Radar`는 특정 색감, BGM, 편집 스타일 등 미묘한 마이크로 트렌드를 감지하여, 여러분이 시장을 선도하는 콘텐츠를 만들 수 있도록 돕는 강력한 도구가 될 것입니다. 초보자분들도 쉽게 구동할 수 있도록 친절하게 안내해 드릴 테니, 걱정 말고 저와 함께 이 바이브의 세계로 뛰어들어 보세요!

## 1. 프로젝트 소개

`VibeWave Radar`는 숏폼 콘텐츠 시장의 '바이브'를 실시간으로 스캐닝하는 AI 에이전트입니다. 아직 일반인들에게는 잘 알려지지 않았지만, 곧 급부상할 잠재력이 있는 특정 색감, 배경음악(BGM), 편집 스타일 등 미묘한 마이크로 트렌드의 '초동 파동'을 포착하는 것이 목표입니다. 감지된 트렌드는 콘텐츠 제작자에게 즉각적으로 알림으로 제공되어, 빠르게 새로운 바이브를 콘텐츠에 적용할 수 있도록 돕습니다.

이 프로젝트는 파이썬으로 구현되었으며, 실제 AI 분석 엔진 대신 텍스트 기반의 시뮬레이션을 통해 바이브 감지 및 트렌드 분석 로직을 체험해 볼 수 있도록 설계되었습니다. 여러분은 이 코드를 통해 오또의 '바이브웨이브 레이더'가 어떻게 작동하는지 이해하고, 미래의 킬러 콘텐츠를 기획하는 데 영감을 얻을 수 있을 것입니다.

## 2. 주요 기능

*   **실시간 바이브 스캐닝 (시뮬레이션 기반)**: 가상의 비디오 데이터를 통해 '바이브 태그'를 추출하고 분석합니다.
*   **마이크로 트렌드 감지 및 알림**: 현재 스캔된 바이브와 과거 데이터를 비교하여 새로운 트렌드나 급증하는 파동을 즉시 감지하고, 알림 메시지를 출력합니다.
*   **새로운 바이브 태그 및 조합 감지**: 완전히 새로운 바이브 태그의 등장이나, 기존 태그들의 새로운 조합 출현을 포착합니다.
*   **감지된 트렌드 보고서 저장**: 감지된 모든 트렌드 알림은 `vibewave_trends.csv` 파일에 자동으로 기록됩니다.
*   **한글 Windows 환경 지원 강화**: 윈도우 환경에서 발생할 수 있는 인코딩 오류(`UnicodeEncodeError`)를 방지하는 코드가 기본으로 포함되어, 안정적인 실행을 보장합니다.

## 3. 시작하기

`VibeWave Radar`를 구동하는 것은 매우 쉽습니다! 아래 단계를 따라해 보세요.

### 준비물

*   **Python 3.7 이상**: 파이썬이 설치되어 있지 않다면, [Python 공식 웹사이트](https://www.python.org/downloads/)에서 다운로드하여 설치해 주세요.

### 설치

`VibeWave Radar`는 외부 라이브러리에 의존하지 않습니다! 파이썬 기본 기능만으로 작동하기 때문에, 별도의 `pip install` 명령이 필요 없습니다. 🚀

1.  **`vibewave_radar.py` 파일 다운로드**: 제공된 소스코드를 `vibewave_radar.py`라는 이름으로 저장합니다.
2.  **가상 환경 설정 (선택 사항이지만 강력 권장)**:
    새로운 프로젝트를 시작할 때 파이썬 가상 환경을 사용하는 것은 좋은 습관입니다. 이는 프로젝트별로 독립적인 파이썬 환경을 구축하여 시스템의 다른 파이썬 프로젝트나 라이브러리와의 충돌을 방지해 줍니다.
    *   터미널 또는 명령 프롬프트를 열고, `vibewave_radar.py` 파일이 있는 디렉토리로 이동합니다.
    *   다음 명령어를 실행하여 `venv`라는 이름의 가상 환경을 생성합니다:
        ```bash
        python -m venv venv
        ```
    *   생성된 가상 환경을 활성화합니다:
        *   **macOS / Linux**: `source venv/bin/activate`
        *   **Windows**: `.\venv\Scripts\activate` 또는 `venv\Scripts\activate.bat`
    *   이제 터미널 프롬프트 앞에 `(venv)`가 표시되면 가상 환경이 성공적으로 활성화된 것입니다.

### 실행 방법

**API 키도, 복잡한 환경 설정도 필요 없습니다!** 파일을 다운로드하고 가상 환경을 활성화했다면, 바로 실행할 수 있습니다.

`VibeWave Radar`는 `scan`과 `simulate` 두 가지 주요 명령을 제공합니다.

## 4. 사용법

### 단일 비디오 스캔하기 (scan 명령)

특정 비디오의 바이브 데이터를 입력하여 실시간으로 트렌드를 감지합니다. `video_data`는 쉼표로 구분된 바이브 태그 문자열입니다.

```bash
python vibewave_radar.py scan --video_id "video_001" --video_data "lofi_hiphop, vintage_filter, warm_tones"
```

**예시:**

```bash
# 새로운 비디오 스캔
python vibewave_radar.py scan --video_id "summer_vlog_01" --video_data "bright_colors, ukulele_bgm, travel_vibe"

# 또 다른 비디오 스캔 (히스토리와 비교)
python vibewave_radar.py scan --video_id "city_night_walk" --video_data "neon_lights, synthwave_music, cinematic_filter"

# 새로운 바이브 조합을 시도
python vibewave_radar.py scan --video_id "my_unique_vid" --video_data "ASMR, cozy_vibes, soft_lighting, lofi_hiphop"
```

### 트렌드 시뮬레이션 실행하기 (simulate 명령)

지정된 수만큼의 가상 비디오 데이터를 자동으로 생성하여 `VibeWave Radar`의 트렌드 감지 기능을 시뮬레이션합니다. 이는 다양한 매개변수를 실험하고 `VibeWave Radar`의 작동 방식을 이해하는 데 유용합니다.

```bash
python vibewave_radar.py simulate [--num_videos N] [--output_file FILENAME] [--history_size SIZE] [--trend_threshold THRESHOLD] [--surge_factor FACTOR]
```

**예시:**

```bash
# 기본 설정으로 10개의 비디오 시뮬레이션 실행
python vibewave_radar.py simulate

# 50개의 비디오를 시뮬레이션하고, 트렌드 감지 파라미터를 조정
python vibewave_radar.py simulate --num_videos 50 --history_size 200 --trend_threshold 0.7 --surge_factor 2.5

# 결과를 'my_custom_report.csv' 파일에 저장
python vibewave_radar.py simulate --num_videos 20 --output_file "my_custom_report.csv"
```

## 5. 프로젝트 매개변수

`simulate` 명령을 실행할 때, 다음 매개변수들을 조절하여 `VibeWave Radar`의 감지 민감도를 변경할 수 있습니다.

*   `--history_size` (기본값: 100)
    *   `VibeWave Radar`가 과거 트렌드를 분석하는 데 사용할 비디오 데이터의 최대 개수를 정의합니다. 이 값이 클수록 더 긴 기간의 트렌드를 고려하지만, 새로운 트렌드에 대한 반응은 느려질 수 있습니다.
*   `--trend_threshold` (기본값: 0.6)
    *   과거 이력에서 특정 바이브 태그가 얼마나 자주 나타나야 '일반적인' 트렌드로 간주할지 결정하는 임계값입니다. 0.0에서 1.0 사이의 값으로, 이 값이 높을수록 더 보편적인 태그만 과거 트렌드로 인정합니다.
*   `--surge_factor` (기본값: 2.0)
    *   현재 비디오에서 감지된 바이브 태그의 출현 빈도가 과거 이력에서의 평균 출현 빈도보다 몇 배 이상 높아야 '급증하는 파동'으로 간주할지 결정하는 요소입니다. 이 값이 높을수록 더 큰 폭의 급증만 트렌드로 감지합니다.

## 6. 결과 파일: `vibewave_trends.csv`

`VibeWave Radar`가 새로운 바이브웨이브 트렌드를 감지하면, 그 정보는 자동으로 `vibewave_trends.csv` 파일에 기록됩니다. 이 파일은 프로젝트를 실행한 디렉토리에 생성되며, 다음 정보를 포함합니다.

*   `timestamp`: 트렌드가 감지된 정확한 시각.
*   `video_id`: 트렌드 감지에 기여한 비디오의 ID.
*   `tags`: 해당 비디오에서 감지된 바이브 태그들.
*   `alert`: `VibeWave Radar`가 발송한 구체적인 알림 메시지.

이 CSV 파일은 여러분의 트렌드 분석 리포트의 훌륭한 자료가 될 것입니다! 오또가 판매할 '탄생 공식' 데이터의 기반이 되는 데이터이기도 하죠. 😉

## 7. ⚠️ 중요 안내 및 주의사항

*   **시뮬레이션 기반 프로젝트**: 이 `VibeWave Radar`는 실제 비디오 분석 AI 엔진이 아닌, 텍스트 기반의 시뮬레이션 로직으로 작동합니다. 이는 실제 숏폼 플랫폼의 데이터를 직접 스캐닝하는 것이 아니며, 코어 로직의 개념을 보여주기 위함입니다.
*   **데이터의 한계**: `_simulate_video_analysis` 함수는 미리 정의된 랜덤 바이브 태그를 사용하거나, 입력받은 텍스트를 파싱하여 태그를 추출합니다. 실제 트렌드 분석을 위해서는 방대한 양의 실시간 비디오 데이터와 정교한 머신러닝 모델이 필요합니다.
*   **트렌드 감지 로직의 단순성**: 현재 트렌드 감지 로직(`_detect_trends`)은 이해를 돕기 위해 간략화되어 있습니다. 실제 상용 서비스에서는 훨씬 더 복잡하고 다층적인 알고리즘이 사용될 것입니다.
*   **활성 가상 환경 확인**: 만약 `python` 명령 실행 시 오류가 발생한다면, 가상 환경이 제대로 활성화되었는지 다시 한번 확인해 주세요.

## 8. 미래 확장성

이 `VibeWave Radar` 프로젝트는 무한한 확장 가능성을 가지고 있습니다!

*   **실제 API 연동**: TikTok, YouTube Shorts 등 실제 숏폼 플랫폼의 공개 API와 연동하여 실제 비디오 데이터를 분석할 수 있도록 확장해 보세요.
*   **고도화된 AI 모델 도입**: 이미지/음악 분석 AI(Vision AI, Audio AI)를 도입하여 비디오에서 직접 색감, BGM, 편집 스타일 등을 자동으로 추출하도록 업그레이드할 수 있습니다.
*   **사용자 인터페이스(UI) 구축**: 웹 기반의 대시보드를 만들어 감지된 트렌드를 시각적으로 보여주고, 알림을 실시간으로 받을 수 있도록 할 수 있습니다.
*   **트렌드 예측 모델**: 단순히 감지를 넘어, 현재의 파동을 기반으로 미래의 트렌드를 예측하는 모델을 추가해 보세요.
