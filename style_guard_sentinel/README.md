# 🛡️ StyleGuard Sentinel (스타일 가드 감시병)

![Python](https://img.shields.io/badge/Python-3.8+-blue?style=for-the-badge&logo=python) ![scikit-learn](https://img.shields.io/badge/scikit--learn-orange?style=for-the-badge&logo=scikit-learn) ![NumPy](https://img.shields.io/badge/NumPy-013243?style=for-the-badge&logo=numpy)

## 💡 프로젝트 소개

**StyleGuard Sentinel**은 AI 시대의 콘텐츠 창작자들을 위한 혁신적인 감시병입니다. AI 기술이 빠르게 발전하면서, 특정 창작자의 고유한 글쓰기 스타일, 화법, 심지어 주제 선정 패턴까지 모방하여 콘텐츠를 생성하는 사례가 늘고 있습니다. StyleGuard Sentinel은 이러한 위협으로부터 창작자들의 독창성을 보호하기 위해 탄생했습니다.

이 프로젝트는 인공지능이 **콘텐츠 제작자의 고유한 스타일을 학습**하고, 이후 웹상의 방대한 텍스트를 감시하며 해당 제작자의 스타일을 **너무나 비슷하게 모방하는 AI 생성 콘텐츠의 출현 징후를 탐지**하여 즉시 제작자에게 경고를 보냅니다. 궁극적으로, 이렇게 발견된 '새로운 AI 스타일 모방 기법'에 대한 익명화된 데이터는 AI 윤리 연구소나 콘텐츠 진위 판별 솔루션 개발사에 판매되어 AI 윤리 및 콘텐츠 진위 판별 기술 발전에 기여하게 됩니다.

--- 

## ✨ 주요 기능

*   **📝 고유 스타일 학습**: 창작자가 제공하는 텍스트 데이터를 기반으로 고유한 글쓰기 스타일을 AI가 학습합니다.
*   **🔍 AI 모방 감시**: 학습된 스타일 프로필을 사용하여 새로운 텍스트 콘텐츠가 특정 스타일을 과도하게 모방하는지 감시합니다.
*   **🚨 실시간 경고**: 스타일 모방이 의심되는 콘텐츠 발견 시 즉시 경고 메시지를 생성합니다.
*   **📊 경고 기록 저장**: 감지된 모든 경고 기록을 JSON 파일로 저장하여 추후 분석 및 활용이 용이합니다.

1.  **프로젝트 파일 다운로드**: `style_guard_sentinel.py` 파일을 로컬 컴퓨터에 다운로드합니다.

2.  **가상 환경 설정 (권장)**: 프로젝트 의존성을 격리하고 관리하기 위해 가상 환경을 사용하는 것을 강력히 권장합니다.
    ```bash
    python -m venv venv

    .\venv\Scripts\activate
    # macOS/Linux
    source venv/bin/activate
    ```

3.  **필요한 라이브러리 설치**: 가상 환경을 활성화한 후, 필요한 파이썬 라이브러리를 설치합니다.
    ```bash
    pip install scikit-learn numpy
    ```

### 3. ▶️ 스크립트 실행 예시

`style_guard_sentinel.py` 파일을 열어 위에서 준비한 텍스트 리스트들을 직접 스크립트 내부에 할당하거나, 파일을 읽어들이는 로직을 추가하여 사용할 수 있습니다. 여기서는 간단한 테스트를 위해 스크립트 하단에 다음과 같은 코드를 추가하여 실행하는 방법을 안내합니다.

**`style_guard_sentinel.py` 파일의 가장 아래에 다음 코드를 추가하세요:**

```python
if __name__ == "__main__":
    # 창작자의 학습 텍스트 데이터 (실제 사용 시에는 더 많고 다양한 텍스트를 제공하세요)
    creator_texts_for_learning = [
        "안녕하세요, 오또입니다. 오늘은 파이썬 스크립트 개발에 대해 이야기해 볼까 합니다. 복잡한 문제를 해결하는 즐거움은 언제나 저를 설레게 합니다.",

        "이번 주말에는 새로운 프로젝트를 구상 중입니다. 사용자 친화적인 인터페이스와 강력한 백엔드 로직을 결합한 솔루션을 목표로 하고 있습니다.",
        "개발자로서의 삶은 끊임없는 학습의 연속입니다. 새로운 기술을 익히고, 더 나은 코드를 만들기 위해 노력하는 과정 자체가 보람입니다.",
        "오또는 항상 여러분의 아이디어를 현실로 만들어 드립니다. 궁금한 점이 있다면 언제든지 문의해주세요."
    ]

    # 감시할 새로운 콘텐츠 리스트 (실제 사용 시에는 웹 크롤링 등으로 수집한 데이터를 사용합니다)
    new_contents_to_monitor = [
        "안녕 친구들, 오늘은 파이썬 코딩 팁에 대해 알아볼 거야. 쉽고 재미있게 배워보자!",
        "최근 인공지능이 인간의 글쓰기 스타일을 모방하는 능력이 매우 발전하고 있습니다. 창작자의 개성을 보호하는 것이 중요해지고 있습니다.",

        "안녕하세요. 오또입니다. 여러분의 개발 생산성을 높여줄 새로운 도구를 소개합니다. 이 도구는 AI 기반으로 작동하며, 코딩 과정을 혁신적으로 변화시킬 것입니다. 기대해주세요.",
        "점심 메뉴로 뭘 먹을지 고민이네요. 추천 좀 해주세요!"
    ]

    # StyleGuard Sentinel 인스턴스 생성
    sentinel = StyleGuardSentinel(creator_name="오또 개발자")

    # 창작자 스타일 학습
    if sentinel.learn_creator_style(creator_texts_for_learning):
        # 콘텐츠 감시 (유사도 임계치는 0.0 ~ 1.0 사이 값, 기본값 0.7)
        sentinel.monitor_content(new_contents_to_monitor, similarity_threshold=0.75)
        
        # 경고 기록 파일로 저장
        sentinel.save_alerts_to_file()
```

```bash
python style_guard_sentinel.py
```

### 4. 📊 실행 결과 확인

스크립트 실행 후, 콘솔에 학습 및 감시 진행 상황과 경고 메시지가 출력됩니다. 만약 AI 스타일 모방이 의심되는 콘텐츠가 감지되면, 현재 디렉토리에 `styleguard_alerts.json` 파일이 생성되며, 해당 파일에 상세한 경고 기록이 저장됩니다.

## ⚙️ 설정

`StyleGuardSentinel` 클래스를 초기화하고 `monitor_content` 메서드를 호출할 때 다음 매개변수를 조정할 수 있습니다.

*   `creator_name` (생성자): 감시할 창작자의 이름을 지정합니다. 경고 메시지에 사용됩니다. (기본값: "Unknown Creator")
*   `similarity_threshold` (`monitor_content` 메서드): AI 스타일 모방으로 간주할 유사도 임계값을 설정합니다. 0.0에서 1.0 사이의 값입니다. 값이 높을수록 더 엄격하게 유사성을 판단합니다. (기본값: 0.7)

## ⚠️ 주의사항 및 경고

*   **정확도 한계**: 이 도구는 텍스트 유사성을 기반으로 스타일을 판단합니다. AI 생성 콘텐츠 탐지는 복잡하며, 100% 정확하지 않을 수 있습니다. **오탐(False Positive)** 또는 **미탐(False Negative)**이 발생할 수 있음을 인지하고 참고 자료로 활용해 주세요.
*   **학습 데이터의 중요성**: 창작자의 스타일을 정확히 학습하려면 충분하고 다양한 양질의 텍스트 데이터가 필요합니다. 학습 데이터가 부족하거나 편향되어 있으면 탐지 정확도가 떨어질 수 있습니다.
*   **언어 지원**: 현재 `TfidfVectorizer`는 `stop_words='english'`를 사용하고 있어 **주로 영어 텍스트에 최적화**되어 있습니다. 다른 언어(예: 한국어)를 사용하려면 해당 언어에 맞는 불용어 처리 및 토크나이저를 적용해야 합니다.
*   **데이터 개인 정보 보호**: 이 스크립트는 로컬에서 동작하며 외부로 데이터를 전송하지 않습니다. 하지만 민감한 텍스트 데이터를 학습하거나 감시하는 경우, 데이터 보안 및 개인 정보 보호 정책을 준수하는 것이 중요합니다.
*   **익명화된 데이터 판매**: 본 프로젝트의 컨셉 상 발견된 'AI 스타일 모방 기법'에 대한 익명화된 데이터 판매가 언급되었으나, 현재 제공되는 `style_guard_sentinel.py` 스크립트는 해당 데이터를 수집하고 `styleguard_alerts.json` 파일로 저장하는 기능까지만 제공합니다. 실제 데이터 판매 기능은 구현되어 있지 않습니다.
